## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| other app/browser -> GET /wishlist/share | title/text/url are attacker-controllable (any site can link to the URL) |
| session flash -> Inertia prop -> Vue | untrusted text rendered in form fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-l1u-01 | Tampering | SharedLink | mitigate | only http/https, no credentials, length cap 2048, control chars rejected; reuses WishRequest::isWebUrl |
| T-l1u-02 | Tampering/XSS | prefill rendering | mitigate | values go only into bound input values, never v-html; title trimmed to title_max |
| T-l1u-03 | Tampering (CSRF/link-forced prefill) | GET route | accept | route only flashes a prefill; it saves nothing and the user must press Save (POST is CSRF protected) |
| T-l1u-04 | Information disclosure | logs/history | mitigate | redirect carries no title/url (session flash); controller does not log; test asserts no log call |
| T-l1u-05 | Elevation | access | mitigate | access:module,wishlist,edit middleware plus EndpointMatrix row; guests via login redirect, SafeIntended keeps same-origin path |
| T-l1u-06 | Information disclosure | service worker | mitigate | network-only navigation, build guard forbids /wishlist/share in precache |
| T-l1u-07 | Denial of service | route | mitigate | throttle:30,1 |
</threat_model>
