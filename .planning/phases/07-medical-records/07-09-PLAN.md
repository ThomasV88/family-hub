## Contracts this plan creates

- `App\Medical\Queries\SystemQuery` (final; class docblock: "Unscoped by design: runs without a viewer (Phase 8 worker, scheduler, outbox). Returns ids, dates or booleans only, never names or record content. Every method has its own test."): `aiConsentFor(string $subjectId): bool` (false without SQL for a non-uuid; false for a missing row). 07-12 adds `documentSubjectId`, 07-15 adds reminder methods.
- `App\Medical\AiConsent` (final): `static allows(MedicalSubject|string $subject): bool` (reads through SystemQuery, never trusts a passed model's in-memory attribute; any Throwable -> false). 07-12 adds `allowsDocument(string $documentId): bool`. Docblock: Phase 8 MUST call it at dispatch and again immediately before invoking the CLI.
- `SubjectQuery::setConsent(Viewer, MedicalSubject, bool $value): bool`: one transaction, single `UPDATE medical_subjects SET ai_consent, ai_consent_changed_at, ai_consent_changed_by WHERE id = ? AND id IN (Visibility::subjectIds($viewer, Edit))`; when a row changed and the value differs, record AuditEvent::MedicalConsentChanged with meta `{subject: uuid, value: on|off}`; a failing audit write rolls the update back; returns false when 0 rows matched (controller aborts 403).
