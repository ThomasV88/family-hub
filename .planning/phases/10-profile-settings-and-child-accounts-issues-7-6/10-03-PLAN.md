## Contracts produced

- `config/profile.php`: `photo_full_px => 512`, `photo_thumb_px => 192`, `photo_max_bytes => 5 * 1024 * 1024`, `name_max => 60`.
- `ProfilePhotoStore::put(User $user, ProcessedImage $img): void` (writes `wish-images/profile-photos/{id}/{ulid}-full.jpg` and `-thumb.jpg` on disk `local`, both writes checked, then forceFill photo_path, photo_thumb_path, photo_version = photo_version + 1, then deletes old files; on any write failure deletes the new files and throws ProfilePhotoWriteFailed), `remove(User $user): void` (clears both paths, bumps version, deletes files), `sweepOrphans(int $olderThanMinutes): int`.
- `ProfileAccess::canEdit(User $actor, User $target): bool`: self -> true; target can sign in -> false; actor is_admin -> true; `ViewerContext::for($actor)->isManagerOf($target->id)` -> true (manager row alone suffices, no Wishlist Edit grant needed, research A2); else false.

- Routes (file `routes/web/profile.php`, middleware `access:authenticated`, `whereNumber('user')`): `POST /people/{user}/photo` name `profile.photo.store` (`throttle:20,1,profile.photo.store`), `DELETE /people/{user}/photo` name `profile.photo.destroy`, `GET /people/{user}/photo/{variant}` name `profile.photo.show` with `whereIn('variant', ['thumb', 'full'])`.
- Shared Inertia prop `avatars`: lazy closure `fn () => AvatarVersions::map()` returning `{ "<id>": <photo_version> }` for users with `photo_path` not null; only for authenticated requests (empty object for guests).
