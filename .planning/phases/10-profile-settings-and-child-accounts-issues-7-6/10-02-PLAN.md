## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> login, two-factor, passkey, Google, reset endpoints | unauthenticated input trying to create a session |
| session cookie -> every web request | an existing session of a later-disabled account |
| scheduler/queue -> mail | automated recipients selection |
