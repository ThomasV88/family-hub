## Why APP_NAME needs a server step

The shared Inertia prop `app.name` (top bar alt text, page title), Laravel's mail header and footer and the default From name all come from `config('app.name')`, which reads APP_NAME from each stack's `app.env` on the server. scripts/server-provision.sh writes app.env only when it is missing, and deploy.sh never edits it, so the existing stacks (`/opt/family-hub`, `/opt/family-hub-staging`) keep APP_NAME="Family Hub" until an operator changes it. The server is changed by hand following the owner's rules: back up the file first, change one key, nothing printed.
