## Phase Goal

**As a** family member with finance access, **I want to** see where our money goes with exact amounts, recurring bills checked against reality, budgets, charts and bank statement import, **so that** the family manages money in one trusted place while private accounts stay private.

<objective>
Build the exact-money core with TDD: a currency allowlist with explicit exponents, a strict PHP parser (manual entry and CSV modes) that never touches floats, a plain decimal formatter, a text normalizer for hashing and hints, the browser formatter/parser (`money.js`) that builds decimal strings from integer minor units for `Intl.NumberFormat`, the `MoneyAmount` component, and a scan test that forbids float money code in every finance directory (including files later plans create).

Purpose: FIN-02 "Money amounts are stored exactly"; locked decisions "no floats anywhere", "NumberFormatter has only English data: format in the browser with Intl using integer minor units and explicit fraction digits, own currency exponent table", "dedupe hash with a transliteration map (Normalizer does not strip Ł/ł)", "no new Composer/npm packages".
Output: 4 PHP classes, money.js, MoneyAmount.vue, 5 test files.
</objective>
