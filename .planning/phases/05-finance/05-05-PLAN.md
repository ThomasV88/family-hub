## Phase Goal

**As a** family member with finance access, **I want to** see where our money goes with exact amounts, recurring bills checked against reality, budgets, charts and bank statement import, **so that** the family manages money in one trusted place while private accounts stay private.

<objective>
TDD the pure CSV pipeline (no DB, no HTTP): decode bytes (UTF-8, UTF-8 BOM, UTF-16 BOM, Windows-1250, ISO-8859-2, CP852) with iconv, read rows with fgetcsv and an explicit empty escape, parse dates strictly from an allowlist, map columns by header name with index fallback into normalized rows (single, split and indicator amount modes), and compute per-account dedupe hashes with in-file ordinals. Synthetic fixtures are generated in code and a small committed set makes byte-level encoding regressions visible.

Purpose: FIN-08; locked decisions "iconv for Windows-1250/ISO-8859-2/CP852", "fgetcsv with escape ''", "strict date parsing with getLastErrors checks", "dedupe hash with a transliteration map", "2 MiB / 5000 rows caps", "profile by header name, date-format allowlist, amount modes single/split/indicator", "synthetic fixtures generated in code (CsvFixtures with iconv) covering 20+ variants", "generic CSV profiles only (no bank-named profiles)", "no new Composer/npm packages".
Output: config/finance.php, 9 import classes, fixture generator + 3 committed fixtures + README, 6 unit test files.
</objective>
