## Contracts this plan creates

- `financeQuery.js`: `financeUrl(path, { account, month, ...extra })` keeps `?account` and `?month` across tabs; `visitFinance(params, { only })` wraps router.get with preserveState/preserveScroll/replace for chip, month, filter and panel changes.
- `labels.js`: `categoryLabel(category, t)` returns category.name or t(`finance.category.default.${category.defaultKey}`) or t('finance.tx.uncategorized') for null; `accountTypeIcon(type)` returns the Lucide component (Landmark, Banknote, PiggyBank, CreditCard).
- `FinanceShell.vue` props: `finance` (object), `current` ('overview'|'transactions'|'recurring'), `showAddFab` (bool); slots default and `actions`; emits `add`.
- `TransactionForm.vue` props: `finance`, `initial` (object or null), `mode` ('new'|'edit'|'record'), `submitUrl` (string), `method` ('post'|'patch'), `lockedFields` (array of field names); emits `saved`, `dirty-change`. The bill panel in 05-12 uses mode 'record' with a different submitUrl.
