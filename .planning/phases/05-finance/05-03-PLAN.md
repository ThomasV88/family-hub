## Matching parameters (Claude's discretion, aligned with the approved UI-SPEC)

The UI-SPEC "Matching hints" fieldset defines an absolute "Allowed difference" amount (default 0.00) and one "Days around the due date" value (1, 2, 3, 5, 7, 10, 14; default 5). So the occurrence carries `toleranceMinor` (absolute, >= 0) and a symmetric `windowDays` (research's percentage tolerance and asymmetric window are replaced by the approved UI contract).

## Contracts this plan creates

- `RecurrenceEngine::between(string $rrule, CarbonImmutable $anchorLocal, string $fromDate, string $toDate, string $timezone, int $cap = 62): array` returning list<CarbonImmutable> (local wall-clock instants whose local date is within [fromDate, toDate] inclusive, ascending, at most $cap). The anchor date itself is the first occurrence (starts_on is always a due date).
- `App\Finance\Recurring\Occurrence` (final readonly): recurringId string, dueDate string Y-m-d, expectedMinor int (> 0, the expense magnitude), toleranceMinor int, windowDays int, accountId string, hint ?string (already normalized), `key(): string` = recurringId.'.'.dueDate.
- `App\Finance\Recurring\MatchCandidate` (final readonly): transactionId string, accountId string, bookedOn string, amountMinor int (signed as stored), kind string ('income'|'expense'|'transfer'), normalizedDescription string.
- `App\Finance\Recurring\Matcher`: `score(Occurrence, MatchCandidate): ?int`, `autoAccepts(Occurrence, MatchCandidate): bool`, `assign(array $occurrences, array $candidates, array $rejectedPairs): list<array{occurrence: string, transaction: string, score: int}>` where $rejectedPairs is a set of 'occKey|transactionId' strings, `rankForManual(Occurrence, array $candidates, int $maxDays = 60): list<MatchCandidate>`.
- `App\Finance\Recurring\BillStatus` (string enum): Upcoming 'upcoming', Paid 'paid', Overdue 'overdue', PaidDifferently 'paid_differently'.
- `App\Finance\Recurring\StatusResolver::resolve(Occurrence $o, ?MatchCandidate $matched, string $today): BillStatus` and `difference(Occurrence $o, MatchCandidate $matched): int` (abs(actual) - expected, signed).
