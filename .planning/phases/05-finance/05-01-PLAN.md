## Format facts (from the codebase)

- lang/*.json is nested JSON for vue-i18n. Plurals are pipe segments: en 2 segments (one | other), sk and pl 4 segments in the order one | few | many | other (FORM_ORDER in resources/js/i18n.js). A literal `@` must be `{'@'}`; `|` is always a plural separator; `{` starts a placeholder. No exclamation marks.
- Server validation messages in this project are translation KEYS (e.g. `wishlist.error.save_failed`) that the client passes through t(); the finance.error.* keys below serve that purpose.
- Existing `audit.detail.*`, `audit.event.finance` and `settings.section.*` objects exist: add keys, never change existing ones.
- Existing `nav.finances`, `module.finances`, `empty.finances` stay unchanged.
