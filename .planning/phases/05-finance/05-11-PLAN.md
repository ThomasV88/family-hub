## Props / JSON contracts (consumed by 05-16 and 05-18)

- GET /finance/import (`Finance/Import`): `finance`, `import`: {accounts: [{id, name, currency}] (visible; the route requires finance edit), profiles: [{id, name, settings (ProfileSpec::toArray)}], history: [{id, createdAt, accountId, accountName, addedCount, status: 'committed'|'undone'}] (batches on visible accounts, any creator, newest first, max 20), limits: {maxBytes, maxRows}, encodings, dateFormats, delimiters (from config)}.
- POST /finance/import/preview (JSON, multipart: file, optional encoding, delimiter, header_row): 200 {suggested: {encoding, reason, delimiter}, encoding, delimiter, headers: list<string>, sample: list<list<string>> (first 5 records after the header row), recordCount} or 422 {error: 'too_large'|'binary'|'decode_failed'|'too_many_rows'|'empty'}. No database writes.
- POST /finance/import (multipart: file, account_id, and either profile_id or settings (ProfileSpec array) with save_profile bool and profile_name): 303 to finance.import.show; profile mismatch → back with error profile_id => finance.imp.err_profile; caps → error file => finance.imp.err_size / err_rows / err_type / err_decode.
- GET /finance/import/{batch} (`Finance/ImportBatch`): `finance`, `batch`: {id, status: 'draft'|'committed'|'undone', accountId, accountName, currency, counts: {total, new, duplicate, probable, invalid}, rows: list<Row> (only while draft), result: null | {added, matched, kept}}; Row: {id, rowNo, bookedOn, description, counterparty, amountMinor: string|null, kind, state: 'new'|'duplicate'|'probable_duplicate'|'invalid', errorCode, include: bool, probable: null | {description, bookedOn, amountMinor: string}, matchName: null (05-18 fills it)}. A draft is visible only to its creator and only while the account is visible; committed/undone batches to anyone who sees the account; otherwise 404 identical to a random id.
