## Props contract (consumed by 05-17)

Finance/Overview: `finance` (FinancePage), `overview`: {hasRecurring: bool, blocks: [Block]} where blocks follow AccountQuery::currencies order (or only the selected account's currency) and are empty when the viewer has no visible accounts. Block: {currency, summary: {incomeMinor, spendingMinor, balanceMinor} (strings; spending is a positive magnitude; balance = opening balances + all rows up to the month end), stillToPay: null | RecurringQuery block (null when hasRecurring is false), budgets: [BudgetRow from 05-12], categorySpending: {totalMinor, top: [{categoryId: ?string, amountMinor, percent}] (max 7), other: null | {amountMinor, percent}, all: [{categoryId, amountMinor, percent}]}, balanceSeries: [{month: 'YYYY-MM', balanceMinor}] (12 entries ending at the selected month)}; `panelBudget`: null | {mode:'new', currency} | BudgetRow (from `?budget=`; unknown id or a budget in a currency the viewer has no visible account in renders the 403 page; `new` without edit renders 403).
Home: prop `financeCard` = {paymentsCount, overdueCount} present ONLY when the user has finance view/edit and at least one visible recurring item; otherwise the key is absent from the props (not null).

## Rules

- Display kind via DisplayKind::sql (05-12): fully visible transfers are excluded from income, spending and category spending; hidden-counterpart legs count by sign.
- Percent of category spending = intdiv(amount * 100 + intdiv(total, 2), total) (half up); no division anywhere else.
- Months are 'YYYY-MM' strings converted to date boundaries; never date_trunc on a date column without ::timestamp; group with to_char(booked_on, 'YYYY-MM') and a SUM(...) OVER (ORDER BY month) window for the running balance; every SUM cast ::bigint.
