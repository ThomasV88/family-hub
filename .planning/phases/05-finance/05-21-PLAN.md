## Server rules (owner's global instructions)

Access with `ssh my-server-agent`; files in /opt belong to `deploy`, so use sudo (`sudo -u deploy ...`); send complex commands as a script over stdin (`cat s.sh | ssh my-server-agent 'sudo bash -s'`). Never print `.env`, `app.env`, `migrate.env` or `secrets/*`. Back up a file before changing it (`*.pre-zmena`). Run `nginx -t` before any reload. Do not restart other stacks (edge, mail, work-tracker). Test on staging first; production only via PR to main. Staging holds synthetic data only (staging:audit must pass); real bank files are used only on the owner's device or a throwaway local stack, never committed and never left on staging.
</context>
