## Deviations from Plan

**1. [Rule 3 - Blocking] `error.email_example` does not compile in vue-i18n.** The string in all three lang files contains a bare `@` (name@example.com), which vue-i18n treats as a linked-message marker ("Invalid linked format"), so `t()` throws. Lang files are off limits in this plan, so 30-Forms.vue wraps the call in try/catch and falls back to `tm()` (raw string). Follow-up for whoever owns lang files: escape as `{'@'}` in en/sk/pl (`error.email_example`); the fallback keeps working after the fix because `t()` then succeeds first. Any other plan using this key will hit the same throw.

**2. TDD order:** tests were written before components but the RED run was not committed separately (one commit per task).
