## Deviations from Plan

1. **[Rule 1 - Bug] Dark danger-fill.** Plan's pair on-primary on danger-fill failed in dark (3.79). Dark `--color-danger-fill` set to `#e0735f`; light stays `#c4503f`. Danger text token values match UI-SPEC.
2. **[Rule 3 - Blocking] axe helper disables `region` rule** (fragments are not pages).
3. **ThemeSwitch legend** is visually hidden (UI-SPEC/plan said legend "Theme"; text is still present for assistive tech).
4. **Radio-name test**: `useId()` is unique per Vue app, so the two-instance test mounts both switches inside one app (as on a real page); separate `mount()` calls would collide by design.
5. **lang files**: plan said keys `theme.label` etc.; files are nested JSON, so `theme: { label, system, light, dark }`.
6. UI-SPEC inline pre-paint script replaced by server attribute + CSS media query (CSP); CSP file unchanged.
