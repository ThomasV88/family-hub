# Phase 01.1 — UI Design Contract

> Visual and interaction contract for the design system and app shell. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: 01.1-CONTEXT.md (locked), sketch findings `.claude/skills/sketch-findings-family-hub/` (locked, tokens in `sources/themes/default.css`), CLAUDE.md stack. Items marked "(discretion)" were decided here under Claude's Discretion. Items marked "(deviation)" intentionally refine a sketch value to meet the WCAG AA baseline required by CONTEXT.md.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn not applicable: Vue 3 + Inertia, no React registry; custom design system ported from sketch patterns) |
| Preset | not applicable |
| Component library | none (custom Vue 3 SFCs in `resources/js/Components/ui/`; native elements first, ARIA only where no native element exists) |
| Styling approach | Plain CSS custom properties in `resources/css/tokens.css` (copy of sketch `default.css` plus deviations below) and scoped/component CSS; no Tailwind, no CSS framework (discretion: sketches are token-driven plain CSS and carry over 1:1) |
| Icon library | Lucide via `lucide-vue-next`, 20px default, 1.75 stroke, `currentColor` (discretion). Icons never carry meaning alone: always an `aria-label` or visible text |
| Font | System stack from tokens: `-apple-system, BlinkMacSystemFont, 'Inter', 'Segoe UI', system-ui, sans-serif`. No webfont download (discretion: keeps precache small, covers SK/PL diacritics natively). Mono: `ui-monospace, 'JetBrains Mono', monospace` for amounts/IDs only |
| Theme mechanism | `data-theme="light|dark"` on `<html>`. Setting values: `system` (default), `light`, `dark`. Persisted in `localStorage` key `fh-theme` plus cookie `fh_theme` (so the server can set the attribute on first paint). An inline script in the root Blade view sets `data-theme` before paint to avoid flash. `system` follows `prefers-color-scheme` live. Also set `color-scheme` and `<meta name="theme-color">` per theme |

## Spacing Scale

Declared values (all multiples of 4; matches sketch `--space-*`):

| Token | Value | Usage |
|-------|-------|-------|
| xs (`--space-1`) | 4px | Icon gaps, inline padding, tag padding-block |
| sm (`--space-2`) | 8px | Compact element spacing, gap between list-row parts |
| 12 (`--space-3`) | 12px | Control inner padding-inline, card inner gaps |
| md (`--space-4`) | 16px | Default element spacing, card padding on phone, form field gap |
| lg (`--space-6`) | 24px | Card padding on tablet/desktop, section padding |
| xl (`--space-8`) | 32px | Layout gaps, content padding on desktop |
| 2xl (`--space-12`) | 48px | Major section breaks, empty-state vertical padding |
| 3xl (`--space-16`) | 64px | Page-level spacing (new token, adds to sketch set; equals collapsed sidebar rail width) |

Exceptions (all multiples of 4 except the first, which is a platform requirement):
- Phone safe-area: bottom bar and FAB add `env(safe-area-inset-bottom)` to their padding.
- Touch targets: minimum 44px hit area on touch layouts (phone and iPad) even when the visible control is 36-40px; achieve with padding or a `::before` hit area, not by enlarging the visual.
- Shell dimensions: sidebar 64px collapsed / 232px expanded; detail panel 360px docked width; topbar 56px; bottom bar 64px content height; FAB 56px circle.
- Control heights: 40px default, 36px compact (desktop pointer only), 44px on touch layouts (`@media (pointer: coarse)` and phone container width).

## Typography

Exactly 4 sizes and 2 weights (deviation: sketch scale has 7 steps; the contract uses a subset. `--text-xs` 12px and tag 11px are NOT used: too small for older readers). Tokens: `--text-sm` 14px, `--text-base` 16px, `--text-xl` 20px, `--text-2xl` 24px. Tokens `--text-xs`, `--text-lg`, `--text-3xl` stay defined for later phases but components in this phase must not use them.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`--text-base`) | 400 regular | 1.5 |
| Label (buttons, inputs labels, tags, nav labels, table headers, captions, muted helper text) | 14px (`--text-sm`) | 600 semibold (captions/helper text 400) | 1.4 |
| Heading (page title, card title, dialog title) | 20px (`--text-xl`) | 600 semibold | 1.2 |
| Display (dashboard headline numbers, empty-state title on style page, app greeting) | 24px (`--text-2xl`) | 600 semibold | 1.2 |

Rules:
- Weights allowed: 400 and 600 only. No 500, 700, italics for emphasis.
- Body text in lists, inputs and dialogs is 16px (also stops iOS Safari zoom on input focus; inputs must never be below 16px).
- Muted text uses `--color-text-muted` and is only used at 14px or 16px.
- Text wraps, never truncates critical content. Single-line ellipsis is allowed only for titles inside list rows and must expose full text via `title`/detail panel. Buttons and tags may wrap to two lines rather than clip (SK/PL/EN length rule).
- Numbers and dates are formatted by locale (`Intl`), amounts use `font-variant-numeric: tabular-nums`.
- `lang` attribute on `<html>` follows the active locale (en-GB, sk-SK, pl-PL) so screen readers and hyphenation behave; `hyphens: auto` on body paragraphs only.

## Color

Light values from sketch `default.css`; dark in `:root[data-theme="dark"]`. Accent usage is deliberately restricted (one blue accent; amber `--color-accent` from the sketch is NOT part of the 10% accent, see below).

| Role | Light | Dark | Usage |
|------|-------|------|-------|
| Dominant (60%) `--color-bg` | #fbfbfa | #191918 | Page background, content area |
| Secondary (30%) `--color-surface` / `--color-surface-2` | #ffffff / #f4f4f2 | #222220 / #2a2a28 | Cards, sidebar, topbar, bottom bar, dialogs, sheets (surface); table header, hover rows, input hover, tag neutral (surface-2) |
| Border `--color-border` | #e8e8e5 | #343431 | 1px dividers, card and control borders (decorative only) |
| Border strong `--color-border-strong` (new, deviation) | #8a8a86 | #6f6f6a | Border of form controls (input, select, checkbox, radio) so they meet 3:1 non-text contrast |
| Text `--color-text` | #1f1f1d | #ececea | All primary text |
| Text muted `--color-text-muted` (deviation) | #6b6b67 | #9a9a95 | Secondary text. Sketch #737370 gives 4.32:1 on surface-2 (fails AA); #6b6b67 gives 4.86:1 |
| Accent (10%) `--color-primary` | #3b6ea8 | #7aa6d6 | See reserved list. 5.27:1 on white, 6.26:1 on dark surface |
| Accent hover `--color-primary-hover` | #2f5c8f | #93b6de | Hover/pressed of primary elements only |
| Accent soft `--color-primary-soft` | #e8f0f8 | #26323f | Selected nav item background, selected chip, focus-adjacent highlights. Text on it uses `--color-primary` (4.58:1 light, passes for 14px semibold only when bold; use `--color-text` for body inside soft areas) |
| On accent `--color-on-primary` | #ffffff | #0f1b27 | Text/icons on solid accent |
| Destructive `--color-danger` (deviation) | #b4432f | #e0735f | Destructive buttons, delete confirmations, error text and error borders, overdue tag. Sketch #c4503f is 4.6:1 on white (passes) but #b4432f gives 5.55:1 for text on tinted backgrounds; use the darker value for text, the sketch value is allowed for non-text fills |
| Success `--color-success` (deviation) | #3d7a54 | #6fb088 | Success text/icons, "done" tag. Sketch #4a8f64 is 3.89:1 (fails AA text); #3d7a54 gives 5.11:1 |
| Warning (tag) `--color-warn-bg` / `--color-warn-text` | #f6ecd9 / #7f5614 | #3a3120 / #d9a05a | Warn tag only. Sketch #9a6a1c was 4.02:1 (fails); #7f5614 gives 5.52:1 |
| Focus ring `--color-focus` | #3b6ea8 | #93b6de | Focus indicator only (same hue as accent) |

Accent reserved for (explicit, closed list):
1. Primary button fill (one primary button per view region)
2. Floating add button (FAB) fill
3. Selected/active nav item (icon + label color and `--color-primary-soft` background, plus a 2px start-edge indicator on the sidebar)
4. Focus ring
5. Links inside body text and the "open" link on dashboard cards
6. Checked state of checkbox, radio, switch; selected filter chip; progress bar fill
7. Selected tab underline and tab label

Accent is NOT used for: decorative icons, card titles, tags (neutral/warn/success/danger variants only), headings, row hover, borders of unselected items, chart colors beyond the single series (charts use accent for the primary series and `--color-text-muted` for comparison series).

Rules:
- `--color-accent` (amber #c7893a/#d9a05a) is kept only as a token for later per-member/status use; no component in this phase uses it (one accent rule).
- Never convey state by color alone: overdue/danger/success always pair color with an icon or text.
- All text/background pairs must be >= 4.5:1; large text and UI component boundaries >= 3:1. The style page lists measured contrast for every token pair in both themes and a Vitest test asserts the ratios.
- Per-member avatar colors (open in sketches): this phase ships a neutral set of 6 muted avatar tints defined as tokens `--avatar-1..6` (discretion), all with text meeting 4.5:1; assignment logic is out of scope.
- Dark theme: no pure black or pure white; shadows reduced to borders where shadow tokens are invisible.

## Layout and Shell Contract

Container queries on `.frame` (name `frame`, `container-type: inline-size`) and `.content` (name `content`). Breakpoints below are container widths, not viewport widths.

| Frame width | Navigation | Add action | Detail panel |
|-------------|-----------|------------|--------------|
| < 640px (phone) | Bottom bar, 5 items: Overview, Tasks, Wishlist, Finances, Health; label under 24px icon; each item min 44px tall hit area and equal width | FAB 56px, bottom-end, 16px above bottom bar | Bottom sheet |
| 640-1023px (iPad portrait) | Sidebar present, collapsed 64px rail by default, toggle expands to 232px; tooltips in rail | Add button in topbar | Overlay (right, 360px, scrim) |
| >= 1024px (desktop/iPad landscape) | Sidebar expanded 232px by default, toggle collapses to 64px | Add button in topbar | Docked right 360px when content width >= 900px, else overlay |

Shell structure (Vue): `AppShell` layout = `SidebarNav` + `main(TopBar + body(content + DetailPanel))` + `BottomNav` + `FabAdd`. `BaseLayout.vue` becomes `AppShell`. Skip link "Skip to main content" is the first focusable element.

- Sidebar open/closed state persisted in `localStorage` key `fh-sidebar`; width transition 200ms ease, disabled under `prefers-reduced-motion`.
- Settings, language switcher and logout live in the avatar menu (topbar, end side). Theme switch (System/Light/Dark) is in the avatar menu and on the style page. Module items not granted to the user are hidden; this phase renders all 5 as static items with Overview and style page routes only, others are disabled-looking placeholders linking to a "coming soon" empty state (discretion).
- Nav labels: "Overview", "Tasks", "Wishlist", "Finances", "Health" (EN); SK "Prehľad", "Úlohy", "Wishlist", "Financie", "Zdravie"; PL "Przegląd", "Zadania", "Wishlist", "Finanse", "Zdrowie". Labels in the bottom bar are 14px/600 and may wrap to 2 lines at most with `overflow-wrap: anywhere`; bar height grows rather than clipping. Full module names appear in page titles.
- Dashboard (Home shell): one card per module, order To-do, Wishlist, Finances, Health; quick add input on top (Enter submits, placeholder only in shell, no persistence in this phase); cards in 1 column below content width 700px, 2 columns from 700px; every card has title (Heading), an "open" link, and a short empty state. To-do card first.
- Page content max width 1200px, centered, horizontal padding 16px phone / 24px tablet / 32px desktop.
- Card: `--color-surface`, 1px `--color-border`, radius 12px, padding 16px (phone) / 24px (wider), no shadow at rest, `--shadow-sm` only for dialogs' trigger lift is not allowed; shadows reserved for sheets, dialogs, menus (`--shadow-md`/`--shadow-lg`).
- Radii: 4px tags/checkbox, 8px controls, 12px cards/dialogs/sheets, full for avatars/pills/FAB.

## Interaction and Accessibility Contract

- Keyboard: every interactive element reachable by Tab in DOM order matching visual order; menus/tabs use arrow keys; dialogs and sheets trap focus and restore it; Esc closes overlays; Enter submits quick add; no keyboard traps.
- Focus: visible ring on `:focus-visible` only, 2px solid `--color-focus` with 2px offset, never removed; ring contrast >= 3:1 against both adjacent colors in both themes.
- Contrast: WCAG AA (values in Color section); borders that identify controls use `--color-border-strong`.
- Touch targets: 44x44px minimum on phone and iPad layouts (`pointer: coarse` or frame < 1024px), 24px minimum spacing equivalence on desktop pointer; bottom bar items and FAB meet 44px+.
- Motion: durations 150-200ms, ease; `prefers-reduced-motion: reduce` disables transitions of width, sheets and skeleton pulse.
- Zoom and text size: layouts work at 200% zoom and 320px width without horizontal scroll (except table content inside its own scroll container). Use `rem` for text, `px` only for borders and fixed shell dimensions.
- Semantics: landmarks `header`, `nav` (aria-label "Main"), `main` (id for skip link), `aside` (detail panel, labelled). One `<h1>` per page. Current nav item `aria-current="page"`. Live regions for toasts/alerts.
- Language: `lang` updated on locale change; all strings through vue-i18n keys in `lang/*.json` (en-GB, sk-SK, pl-PL), no hardcoded UI text, including aria-labels.
- Text length: shell and style page verified with SK and PL strings; add a pseudo-long test (strings 40% longer) in Vitest component tests; no fixed-width containers around text.
- Automated checks: `axe-core` via `vitest-axe` (or `jest-axe` equivalent) in jsdom on style page sections and shell in light and dark and in en/sk/pl; Playwright axe run is optional for staging (discretion). Contrast ratio unit test over token pairs. Color-contrast rule in jsdom is unreliable, so the token-pair test is the authoritative contrast check.
- No private data cached: this phase adds no runtime caching; theme and sidebar preferences are the only new client storage (no personal data).
