## Fixed Issues

### WR-01: Body scroll lock is not re-entrant
**Files:** `resources/js/Components/ui/useScrollLock.js` (new), `UiDialog.vue`, `UiDetailPanel.vue`
**Commit:** da53f5f
**Fix:** Shared counter lock; the original overflow is saved on 0 to 1 and restored on 1 to 0. Fixed: requires human verification.

### WR-02: Docked panel traps Tab
**Files:** `UiDetailPanel.vue`
**Commit:** 57cf74d
**Fix:** Trap only when modal. Docked mode focuses the heading (`tabindex="-1"`) and restores focus on close. Fixed: requires human verification.

### WR-03: Panel mode change while open leaves stale trap and lock
**Files:** `UiDetailPanel.vue`
**Commit:** ed354de
**Fix:** One watcher on `[open, modal]` tears down the old trap/lock and re-applies them to the new container. Fixed: requires human verification.

### WR-04 and WR-05: Focus trap visibility and initialFocus
**Files:** `useFocusTrap.js`
**Commit:** 7a1a805 (one commit for both, same file and closely coupled)
**Fix:** Computed-style visibility filter (no `offsetParent`, since jsdom has no layout), excludes `[hidden]`, `[inert]` and hidden inputs, adds `summary`, `contenteditable`, media controls. `resolve()` uses `isRef` and requires an `HTMLElement`. Fixed: requires human verification.

### WR-06: Toast pause/resume
**Files:** `UiToastRegion.vue`
**Commit:** ab4924a
**Fix:** `pause` is idempotent, hover and focus tracked separately, `focusout` ignores moves within the toast. Fixed: requires human verification.

### WR-07: Theme drift between localStorage and cookie
**Files:** `resources/js/theme.js`
**Commit:** cc79ede
**Fix:** Extracted `writeThemeCookie`; `initTheme()` rewrites the cookie when the stored preference differs from the server-rendered `data-theme-pref`. The inline-nonce head script was not added.

### WR-08: Update banner and toast overlap
**Files:** `PwaUpdateBanner.vue`, `UiToastRegion.vue`
**Commit:** 179a516
**Fix:** While visible, the banner publishes `--fh-banner-lift` and the toast region offsets above it. The banner is centered with logical properties (`inset-inline`, auto margins), with no `left`/`translateX`. Fixed: requires human verification (visual).

### IN-01: Style-guide link and route used different predicates
**Files:** `config/app.php`, `routes/web.php`, `StyleGuideController.php`, `HandleInertiaRequests.php`, `AccountMenu.vue`
**Commit:** eee5c08
**Fix:** One allowlist `app.style_guide_environments`. The route is always registered (route:cache safe) and the controller guards with the allowlist. The shared prop `app.styleGuide` drives the menu link. `app.env` is kept because the staging banner uses it.
