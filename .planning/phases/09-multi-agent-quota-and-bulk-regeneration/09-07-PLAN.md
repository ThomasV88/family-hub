- `CopilotRequest` (final, readonly): `workDir`, `prompt`, `images` (absolute paths inside workDir), `?model` (already validated), `timeoutSeconds`, `usagePath` (`<work>/usage.json`).
- `CopilotRunner` (final; the only place that builds or spawns `copilot`):
  - `exec(CopilotRequest $r, ?Closure $shouldAbort = null): ProcessResult`. Creates `<work>/copilot-home/` (0700), copies `<ai.copilot.home>/config.json` into it with mode 0600 when present, writes `settings.json` as `{}`, creates `<work>/tmp` and `<work>/logs`. Argv exactly as research Code Examples (`-p <prompt> -s --no-ask-user --no-color --stream off --available-tools --deny-tool=shell --deny-tool=write --deny-tool=read --deny-tool=url --deny-tool=memory --disable-builtin-mcps --disable-mcp-server github-mcp-server --no-custom-instructions --disallow-temp-dir --no-auto-update --disable-client-telemetry --no-experimental --log-level none --log-dir <work>/copilot-home/logs --sync-session=off --max-ai-credits <ai.copilot.max_ai_credits> --usage-output-file <usagePath>`, then `--model <id>` when set, then `--attachment <path>` per image). Child env by `env -i` allowlist only: `PATH=<binary dir>:/usr/bin:/bin`, `HOME` and `COPILOT_HOME` = the per-run home, `COPILOT_CACHE_HOME=<ai.copilot.cache>`, `COPILOT_AUTO_UPDATE=false`, `COPILOT_TELEMETRY_DISABLED=true`, `NO_COLOR=1`, `TZ=UTC`, `LANG=C.UTF-8`, `TMPDIR=<work>/tmp`; started through `setsid`, cwd = workDir, stdin closed. Stdout is appended to `<work>/reply.txt` in the poll loop and capped at `ai.caps.result` (over the cap: `outputCapped`, file truncated and ignored); stderr is kept only as a rolling window for scanning plus a byte counter. When the exit code is non-zero, `QuotaSignatures::match('copilot', stderrWindow, now)` and the `ai.copilot.auth_failure_patterns` check run on stderr only. Timeout, idle timeout, abort and process-group kill as in CodexRunner. The per-run home is removed by the caller's `WorkDir::cleanup()` (nothing else deletes paths).
  - `loginStatus(): LoginState`: reads `<ai.copilot.home>/config.json` (never runs the CLI); strips lines starting with `//`; JSON-decodes; any key path from `ai.copilot.login_keys` holding a non-empty value -> `LoggedIn`; file missing or no marker -> `LoggedOut`; unreadable or invalid JSON -> `Unknown`. Returns the enum only; no value is kept or logged.
  - No version method here: the startup version check lives in Preflight (09-08), which already runs the Codex `--version` check itself.
- `CopilotAgent` (final, implements Agent): `__construct(?CopilotRunner $runner = null, ?string $model = null)` (valid model overrides `ai.copilot.model`); `key()` 'copilot'; `modelLabel()`; `loginStatus()` delegates; `extract(AgentInput $input, ?Closure $shouldAbort = null): AgentOutcome` builds `PromptBuilder::buildInline()`, runs, maps in the research Q2 order: aborted; timeout/idle/output cap (terminal, no repair); `JsonReply::decode` + `ExtractionValidator::inspect` ok -> ok (even with exit 1); quota signature with no valid output and exit non-zero -> `QuotaExhausted` (+resetAt, minutes); auth signature -> `Auth`; no stdout bytes and exit non-zero -> `CliError`; otherwise the inspect outcome (`InvalidOutput`/`NoOutput`). Only for `InvalidOutput`, not aborted, and with at least `ai.copilot.repair_min_seconds` left before the deadline, one fresh second call with `buildInline($issues)` and the same images (never `--resume`, never the previous reply), mapped the same way without a further repair. Durations of both calls are summed into one outcome. Recorded model: the configured valid model, else the first key of `usage.json` `modelMetrics` passing `ModelId::isValid`, else 'default'. Per-call timeout from the deadline as in CodexAgent (below `ai.timeouts.min_call` -> `Timeout` without spawning). The reply file is deleted before the repair call.
