- `Preflight::envKeysClean()` covers every name in `ai.forbidden_env` (now including GH_TOKEN, GITHUB_TOKEN, COPILOT_GITHUB_TOKEN, COPILOT_ALLOW_ALL, COPILOT_PROVIDER_BASE_URL, COPILOT_PROVIDER_API_KEY, COPILOT_PROVIDER_API_KEY_COMMAND, COPILOT_PROVIDER_BEARER_TOKEN, COPILOT_OFFLINE); non-empty values only, names reported as codes, never values. `GH_HOST` is not listed (harmless).
- `problems()` adds, always checked (the image always contains both CLIs, independent of the admin switch): `copilot_binary_missing` (not executable), `copilot_version_mismatch` (runs `<binary> --version` under `env -i PATH=... HOME=<temp> COPILOT_HOME=<temp> COPILOT_CACHE_HOME=<ai.copilot.cache>`, parses `(\d+\.\d+\.\d+(?:-[0-9A-Za-z.]+)?)`, compares with `ai.copilot.version`; never `copilot version`), `copilot_cache_missing` (no `pkg/*/*/.extraction-complete` under the cache), `copilot_home_unwritable`, `copilot_home_in_tmp` (home under the system temp dir or the work root), `copilot_model_invalid` (configured fallback `ai.copilot.model` set and not `ModelId::isValid`). The temp home used for the version check is removed with the existing safe tree removal.
- `WorkDir::root()` additionally refuses a root that equals the Copilot home, lies inside it or is a parent of it (same logic as the Codex home).
