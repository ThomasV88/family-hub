## Phase Goal

**As a** family admin who runs the AI document reading, **I want to** choose which AI agents read documents and in what order, have runs wait out or route around an exhausted usage limit, and re-read past documents in bulk with a dry run first, **so that** document reading keeps working on our subscriptions while nobody's accepted data is overwritten and no private content reaches me or any log.

<objective>
The agent selection layer: settings read and admin writes, the ordered registry with candidate selection and earliest resume, per-agent cooldown with the ladder and the Copilot daily ceiling, and login checks for both agents.

Purpose: AI-05 (order, model per agent, login health), AI-06 (fallback candidates, cooldown, waiting resume time). CONTEXT "per agent an enable switch, an order (move up / move down), a model field (empty = CLI default; validated identifier pattern) ... audited content-free", "Codex enabled at position 1; Copilot disabled until the admin enables it", "cooldown_until (parsed reset time if the CLI prints one, else a configured default ... longer ladder up to 24h on repeated hits)", "falls back to the next enabled, healthy, not-cooling-down agent in order"; research C1 (Copilot health from the local marker plus run outcomes), Q3 "Cooldown ladder and storage" (cooldown lives on the worker-written ai_agent_status, not the admin table), "Selection" (no caching, unknown login is runnable, expired agents excluded from earliestResume), Q8 (Copilot daily ceiling, bulk first-agent-only), anti-pattern "Memoising agent settings in the singleton AgentRegistry".
PROVISIONAL (09-20): ladder values, Copilot ceiling 30, `ai.bulk.fallback_agents` false, "last enabled agent cannot be switched off" (UI-SPEC PROVISIONAL 2), enabling an agent in any non-logged-in state allowed (UI-SPEC PROVISIONAL 3, a defaults-level extension of CONTEXT's "Not checked yet" wording per the UI checker follow-up).

## Contracts

- `AiAgentSettingsQuery` (final, App\Medical\Queries; docblock "Admin-only agent settings and the worker's read side. Content-free: agent keys, booleans, positions and validated model ids."):
  - `all(): list<array{agent: string, enabled: bool, position: int, model: ?string}>` ordered by position; agents in `ai.agents` without a row fall back to defaults (codex true 1, copilot false 2); an invalid stored model reads as null.
  - `enabledKeys(): list<string>` ordered; `model(string $agent): ?string`.
  - `setEnabled(User $admin, string $agent, bool $enabled): array{ok: bool, reason: ?string, agents: list<...>}`; `setModel(User $admin, string $agent, ?string $model)`; `move(User $admin, string $agent, string $direction, ?int $expectedPosition = null)`. Each runs in one transaction with `lockForUpdate` on all settings rows: unknown agent -> reason 'unknown'; disabling the last enabled agent -> 'last_enabled'; invalid model (ModelId) -> 'invalid_model' (empty string becomes null); `expectedPosition` given and not the agent's current position -> 'stale'; moving past an end -> ok with no change; unchanged value -> ok, no write and no audit. Otherwise `AuditLogger::record(AuditEvent::AiAgentSettingChanged, $admin, ['agent' => ..., 'field' => 'enabled'|'model'|'position', 'value' => 'on'|'off'|<validated model>|'default'|<new position as string>])` first, then the update (move swaps both positions under the deferred unique constraint and audits the moved agent only), with `updated_by` and `updated_at`.
- `AgentHealth` (per agent everywhere; default argument 'codex' kept for Phase 8 callers): `recordQuotaHit(string $agent, ?CarbonImmutable $resetAt, ?int $defaultMinutes, ?CarbonImmutable $now = null)` (hits increment when the previous hit is within `ai.quota.ladder_reset_hours`, else restart at 1; cooldown = resetAt when given (already buffered and clamped by QuotaSignatures), else max(defaultMinutes, ladder[min(hits, 4) - 1]) minutes; sets last_quota_at); `recordSuccess` also clears quota_hits and cooldown_until; `cooldownUntil(agent): ?CarbonImmutable` (future values only); `coolingDown(agent): bool`; `dailyCeilingReached(agent): bool` (copilot only, `ai.copilot.daily_runs` > 0: count of `ai_calls` with agent 'copilot' and status in (succeeded, failed) since local midnight in `ai.local_timezone`, read through `AiCall::query()->toBase()`); `ceilingResetAt(agent): ?CarbonImmutable` (next local midnight when reached); `snapshot(agent)` adds `cooldownUntil`. `runnable(agent)` keeps the Phase 8 meaning (unknown is runnable, expired/not responding is not).
- `AgentRegistry` (no memoised state): `all(): list<Agent>` = one instance per key in `ai.agents`, each constructed with `AiAgentSettingsQuery::model(key)` (CodexAgent, CopilotAgent model overrides); `find(key)`; `enabled(): list<Agent>` in saved order; `primary(): Agent` = first enabled (kept for compatibility); `candidates(array $excludeKeys = [], bool $bulk = false): list<Agent>` = enabled, not excluded, runnable, not cooling down, ceiling not reached; with `$bulk` and `ai.bulk.fallback_agents` false only the first enabled agent is considered (empty list if it is not a candidate); `nextCandidate(array $tried, bool $bulk = false): ?Agent`; `earliestResume(bool $bulk = false): ?CarbonImmutable` = min over the same considered agents whose login is runnable of (cooldownUntil, ceilingResetAt), null when none; `anyRunnable(): bool` = at least one enabled agent with a runnable login (cooling down still counts as available, UI-SPEC Screen 2); `providers(): list<string>` = enabledKeys().
- `CheckLoginJob`: for every agent in `AgentRegistry::all()` (enabled or not) records `loginStatus()` via `AgentHealth::recordCheck`; still on `ai.control_queue`, unique.
