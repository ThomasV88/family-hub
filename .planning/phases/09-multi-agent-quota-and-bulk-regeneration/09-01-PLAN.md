## Phase Goal

**As a** family admin who runs the AI document reading, **I want to** choose which AI agents read documents and in what order, have runs wait out or route around an exhausted usage limit, and re-read past documents in bulk with a dry run first, **so that** document reading keeps working on our subscriptions while nobody's accepted data is overwritten and no private content reaches me or any log.

> The ROADMAP Phase 9 goal is outcome-shaped, not a user story; this story follows the Phase 8 precedent (08 plans framed their own story) and restates the ROADMAP goal and the three success criteria without adding scope.

<objective>
Ship all Phase 9 copy in one early plan (UI-SPEC Copywriting Contract: "added in lang/en.json, lang/sk.json, lang/pl.json in one early plan") plus the two content-free audit events the admin backends write.

Purpose: AI-05 (agents section copy, audited settings changes), AI-06 (waiting, quota-timeout, provenance, provider lines, provider-aware notice), AI-07 (bulk panel copy, audited bulk actions). CONTEXT "audited content-free (who, agent, changed field names ...)" and "a bulk run ... audited content-free (admin id, scope, counts)"; research Q4 "New audit events"; research pitfall 11 (exhaustive match); UI-SPEC checker follow-ups (accessible names "Pause bulk run"/"Resume bulk run", EN waiting detail "We will try again automatically.").
Planner decisions recorded here (both flagged for the owner in 09-20 and for native review):
- Model identifier rule: the UI-SPEC PROVISIONAL pattern allowed slashes and 64 characters and said the plan may tighten it and must equal the server rule. The server rule already in production code (CodexRunner::isValidModel, research Q4 DB CHECK) is `^[A-Za-z0-9][A-Za-z0-9._:-]{0,59}$`, so the copy becomes "Use letters, numbers, dots, dashes or colons only, up to 60 characters." (SK/PL drafts adjusted to the same meaning).
- Copilot-only notice: the UI-SPEC gives a notice for Codex only (the Phase 8 notice) and for both providers; it has no text when only Copilot is on. Add `health.ai.notice.github_title` "Send this document to GitHub?" and `health.ai.notice.github_body` (same sentence pattern as the both-provider body, naming GitHub only) so the disclosure stays truthful in every combination (UI-SPEC privacy contract "Provider disclosure stays truthful").
Output: three lang files, one Vitest parity file, two audit events with rendering and tests.
</objective>
