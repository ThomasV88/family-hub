## Contracts

- `aiWhen.js`: `formatWhen(iso, locale, timeZone)` -> time only (HH:MM, 24 h in sk/pl, locale default in en) when the date is today in the family time zone, otherwise short weekday plus time ("Tue 03:10"), via `Intl.DateTimeFormat`; the caller always wraps it in `<time datetime>`.
- `AiStatusTag.vue` new props `availableAt` (ISO|null), `failureCode` (string|null), `now` (for tests): status waiting with a future availableAt -> neutral tag, Hourglass (aria-hidden), text `health.ai.status.waiting` with `{when}` inside `<time>`; waiting with a past availableAt -> `waiting_soon`; waiting without availableAt -> `waiting_short` (list rows); failed keeps the Phase 8 tag (the quota-timeout difference is the detail line in RunAiControl). Tags wrap, never truncate.
- `AiProvenanceLine.vue`: props `agent` (key), `model` (string|null); muted 14/400 line `health.ai.provenance.with_model` / `.without_model` with the agent display name (OpenAI Codex / GitHub Copilot); text interpolation only.
- `RunAiControl.vue`: waiting behaves like queued/running (tag + detail `waiting_detail` + secondary "Cancel run" with Ban; same cancel endpoint, toast "Run cancelled", focus back to Run AI); failed with failureCode quota_timeout -> detail `quota_timeout_detail` and "Run AI again"; ready -> provenance line under the "{n} suggestions to review." detail; the permanent provider line from `ai.providers`: only codex -> `provider_codex`, both -> `provider_both`, only copilot -> `provider_copilot`; notice: shown when `noticeAcknowledged` is false; variant by providers: codex only -> the Phase 8 notice keys, both -> `notice.multi_*`, copilot only -> `notice.github_*`; buttons and default focus unchanged ("Keep document private" default focus, Esc and backdrop equal it); the same request records the acknowledgment and queues the run. Announcements via the single status region on entering waiting ("Waiting for AI quota. Retrying after {when}.") and the Phase 8 transitions; aria-busy on the status block while waiting. Cooling-down agents do not make Run AI unavailable (only `available` false does).
- `AiNoticeDialog.vue`: accepts a `variant` prop (codex | multi | github) selecting title and body keys.
- `useAiStatus.js`: when any watched document is waiting, poll every 60 s while `document.visibilityState === 'visible'` (pause on hidden, resume on visibilitychange), stop on terminal states, stop after 60 minutes of continuous visible waiting and expose a `stalled` flag that RunAiControl renders as `health.ai.status.still_waiting`; a change from waiting to queued/running returns to the Phase 8 5 s / 15 s / 15 min schedule.
- `AiReview.vue`: provenance line under the status tag row; when `newerWaiting` is set, a neutral tag with Hourglass "A newer run is waiting for AI quota, retrying after {when}" and a ghost "Cancel run" (Edit only), older proposal fully reviewable; a waiting extraction opened directly shows the status block (tag, detail, Cancel run) instead of panes.
