## Contracts

- `CodexRunner`: env allowlist gains `TZ=UTC`; `isValidModel` returns `ModelId::isValid`; in the poll loop, wherever `matchesAuth` runs on the stderr window and on JSONL lines of type `error`/`turn.failed`, also run `QuotaSignatures::match('codex', <same window>, now)` and keep the first hit (minutes, resetAt) as flags only; the `-o` result file and the final agent message are never scanned. `ProcessResult` is built with `quotaSignature`, `quotaMinutes`, `quotaResetAt` (09-04 members).
- `CodexAgent::__construct(?CodexRunner $runner = null, ?string $model = null)` (keep the Phase 8 signature shape; add the trailing optional model): a valid `$model` overrides `config('ai.codex.model')`; an invalid one is ignored. Per-call process timeout: when `AgentInput::$deadline` is set, `min(config process timeout, deadline - now - 5)`; when that is below `ai.timeouts.min_call` the agent returns a `Timeout` failure without spawning. Outcome mapping order: aborted; timeout/idle/output cap; valid result -> ok (even with non-zero exit or quota text on stderr); `quotaSignature` and exit code non-zero -> failure `QuotaExhausted` with `quotaResetAt`/`quotaMinutes`; auth signature -> `Auth`; then the Phase 8 remaining mapping.
- `FakeCodex` adds `quota(string $stderr)` (stderr text, exit 1, no result file), `quotaEvent(string $message)` (JSONL `turn.failed` event with the message, exit 1), `quotaInAnswer(string $message)` (writes the message as an invalid `-o` result and on stdout, exit 0) and `quotaWithValidResult(string $stderr)` (golden result file plus quota text on stderr, exit 0).
