## Contracts

- `JsonReply` (final): `decode(string $path): ?string` reads at most `ai.caps.result` bytes; trims; if the text starts with a line that is exactly three backticks optionally followed by `json` and ends with a line of three backticks, removes exactly that one pair; returns the remainder only if it starts with `{` and ends with `}` and `json_decode` yields an object; otherwise null. No other repair (no trailing-comma fixing, no prose stripping).
- `ExtractionValidator::inspect(string $json): array{outcome: ExtractionOutcome, issues: list<string>}`: runs the same rules as `validate` and records `path:rule` per failure, at most 20, from this vocabulary only: `json_syntax`, `root:not_object`, `root:schema_version`, `root:keys_missing:<field from the rule table>`, `root:keys_unexpected` (count is not included), `<section>[<int>].<field>:<rule>` where section and field come from the rule table and rule in {required_empty, date_format, enum, too_long, type}, `<section>:too_many_items`. An unexpected key name or any value is never echoed. Every issue matches `/^[a-z_]+(\[\d+\])?(\.[a-z_]+)?:[a-z_]+(:[a-z_]+)?$/`.
- `PromptBuilder::buildInline(?array $issues = null): string` = `build()` + the content of `resources/ai/prompt.inline-json.v1.md` with the compact schema (`json_encode(ExtractionSchema::decoded(), JSON_UNESCAPED_SLASHES)`) and the sentence "Reply with exactly one JSON object and nothing else: no code fence, no commentary." When issues are given, appends the static repair block "Your previous reply was rejected. Problems: <codes joined by ', '>. Reply again with ONLY the JSON object." after dropping any code that does not match the issue pattern and keeping at most 20.
