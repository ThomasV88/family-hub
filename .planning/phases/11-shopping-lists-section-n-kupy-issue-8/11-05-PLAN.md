- Responses: writes answer 303 (back, or to the new list for store/copy/finish-with-carry) with a flash toast key; store adds flash data `open_picker = true` (UI-SPEC screen 2: the picker opens on a new empty list); service 403/404/409/422 pass through.
- FormRequests: names trimmed, max per config; `quantity` normalised in `prepareForValidation` (strip spaces, comma to dot), rule `regex:/^\d{1,3}(\.\d{1,2})?$/` plus > 0 (error key `shopping.error.quantity`); `state` enum; `remind_at` accepted as a local `Y-m-d\TH:i` string in `config('family.timezone')`, converted to UTC, must be after now (error `shopping.error.reminder_past`), nullable to remove; `responsible_id`, `contributor_ids[]`, `viewer_ids[]` integers (eligibility is checked by the services); `copy.name` required max 80; `carry_name` nullable max 80.
- `ListPayload::index(User, string $tab, int $page)`: `lists` (open and locked visible lists, each `{id, name, status, store: {id, name, logoVersion}|null, responsible: {id, name}, remindAt (ISO in family timezone)|null, reminderPassed, itemsCount, boughtCount, unavailableCount, abilities: {copy}}`, ordered by remind_at ascending with nulls last, then created_at descending per UI-SPEC screen 1), `archive` (paginated `config('shopping.archive_per_page')`, done visible lists by done_at desc with `doneAt` and `storeName`), `counts {open, archive}`, `stores`, `responsibleCandidates` (eligible responsible people `{id, name, isChild}`), `canCreate`. Use subselect counts, never load items for the overview.
- `ListPayload::show(User, ShoppingList)`: `list {id, name, status, store, storeName, creator {id, name}, responsible {id, name} (effective), responsibleFallback {previousName|null}|null (only for the creator), remindAt, reminderPassed, reminderSent, lockedAt, doneAt, source {id, kind}|null}`, `items [{id, name, quantity (string), unitId, note, state, catalogItemId, imageVersion|null}]` by position, `abilities` (ShoppingAccess::abilities), `members {contributors: [{id,name,isChild}], viewers: [...]}`, `candidates {responsible, contributors, viewers}` (only when abilities.manageMembers or changeResponsible), `responsiblePushEnabled` (only when abilities.setReminder: NotificationPreferences push enabled and a PushSubscription exists for the effective responsible), `catalog [{id, name, defaultUnitId, imageVersion|null}]` (only when abilities.editItems), `units [{id, key|null, names {en, sk, pl}|null}]`, `stores [{id, name, logoVersion}]`. No e-mail address of any member, no file path, no other user's preference beyond the one boolean.
