## Decisions applied (UI-SPEC wins over research where it states behaviour)

Custom units are deleted (not archived); items and catalog rows then show the quantity without a unit (FK ON DELETE SET NULL). Built-ins are never deleted (enforced in 11-04).
- Store deletion is allowed (UI-SPEC: "Those lists will have no store"), so `shopping_lists.store_id` is ON DELETE SET NULL; finished lists keep the `store_name` snapshot written at finish (11-03).
- Catalog and store names unique case- and accent-insensitively (UI-SPEC) via a `name_key` column filled in PHP by `NameKey::from()` (`Str::lower(Str::ascii(trim, inner whitespace collapsed))`), unique index on `name_key`. No Postgres extension needed.
- Quantity (UI-SPEC section 10): `numeric(5,2)`, CHECK `quantity > 0 AND quantity <= 999.99`; at most 2 decimals.
- D13: no starter catalog or stores in migrations; the nine built-in units only (pcs, g, kg, ml, l, pack, bunch, tbsp, tsp, positions 1 to 9).

## Contracts (tables)

- `shopping_units`: id, key varchar(20) null unique, name_en/name_sk/name_pl varchar(12) null, position smallint, created_by FK users nullOnDelete, timestamps. CHECK `shopping_units_kind`: (key not null and all three names null) or (key null and all three names not null). Partial unique indexes on lower(name_en), lower(name_sk), lower(name_pl) where not null.
- `shopping_stores`: id, name varchar(60), name_key varchar(60) unique, logo_path null, logo_thumb_path null, image_version int default 0, created_by FK users nullOnDelete, timestamps.
- `shopping_catalog_items`: id, name varchar(80), name_key varchar(80) unique, default_unit_id FK shopping_units nullOnDelete, image_path null, thumb_path null, image_version int default 0, created_by FK users nullOnDelete, timestamps.
- `shopping_lists`: id, name varchar(80), store_id FK nullOnDelete, store_name varchar(60) null, creator_id FK users restrictOnDelete, responsible_id FK users nullOnDelete, status varchar(8) default 'open' CHECK in (open, locked, done), locked_at, locked_by FK nullOnDelete, done_at, done_by FK nullOnDelete, remind_at, reminder_enqueued_at, source_list_id FK shopping_lists nullOnDelete, source_kind varchar(5) null CHECK in (copy, carry), timestamps (all timestampTz). CHECKs: (status = 'done') = (done_at is not null); status <> 'locked' or locked_at is not null; source_list_id is null or source_kind is not null. Unique partial index `shopping_lists_one_carry` on (source_list_id) where source_kind = 'carry'. Indexes: status, creator_id, responsible_id, (done_at desc) where status = 'done', (remind_at) where remind_at is not null and reminder_enqueued_at is null.
- `shopping_list_members`: list_id FK cascade, user_id FK cascade, role varchar(12) CHECK in (contributor, viewer), created_at; PK (list_id, user_id); index user_id.
- `shopping_items`: id, list_id FK cascade, catalog_item_id FK nullOnDelete, name varchar(80), quantity numeric(5,2) default 1 with the CHECK above, unit_id FK shopping_units nullOnDelete, note varchar(200) null, state varchar(12) default 'pending' CHECK in (pending, bought, unavailable), state_changed_at null, state_changed_by FK users nullOnDelete, position int, created_by FK users nullOnDelete, timestamps; index (list_id, position).
- Enums in `App\Shopping`: `ListStatus` (open, locked, done), `ItemState` (pending, bought, unavailable), `MemberRole` (contributor, viewer), `SourceKind` (copy, carry).
- `config/shopping.php`: catalog image full 512 / thumb 192 px, max 5 MiB (5242880); store logo full 320 / thumb 128 px, max 2 MiB (2097152); name max list 80, catalog 80, store 60, unit 12, note 200; quantity max 999.99; items per add request 50; mail per_send 5, per_user_hour 10, per_user_day 30, per_recipient_day 5 (research A1); archive per_page 20.
- Models: guarded/fillable per repo convention, casts for enums and timestamps, `quantity` cast to string (decimal:2) never float. Relations: list -> creator, responsible, store, items (ordered by position), members, memberUsers; item -> list, catalogItem, unit; catalog item -> defaultUnit. `ShoppingCatalogItem` and `ShoppingStore` fill `name_key` in a `saving` hook. `ShoppingUnit::isBuiltIn()`.
- Factories: list (open, with creator and responsible), item, catalog item, store, custom unit; states `locked()`, `done()`.
