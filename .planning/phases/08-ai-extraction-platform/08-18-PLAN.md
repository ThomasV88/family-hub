## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-84 | Tampering/XSS | model output rendered as HTML | mitigate | Text interpolation only; v-html grep gate; literal-HTML test |
| T-08-85 | Information disclosure | review drafts or page images persisted | mitigate | No storage APIs, encryptHistory on, server no-store |
| T-08-86 | Tampering | user mistakes AI text for verified data | mitigate | Always-visible warning, per-entry decisions, no Accept all (PROVISIONAL 2), records labelled AI-extracted/Unverified (08-20) |
| T-08-87 | Repudiation | silent duplicate saves | mitigate | No optimistic UI; server idempotency (08-15); duplicate response shows real state |
