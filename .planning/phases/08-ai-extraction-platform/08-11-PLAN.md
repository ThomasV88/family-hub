## Contract

`GET /health/people/{person}/documents/{document}/pages/{page}` name `health.documents.page`, middleware `access:module,health,view`, `throttle:120,1,health.documents.page`. Controller: `page` must match `^[1-9][0-9]{0,2}$` else 403; resolve through the same visibleDocument() (identical 403 for hidden/unknown/malformed); `kind !== 'pdf'` -> 403; page > `min(pageCount, ai.pdf.view_max_pages)` -> 403; render with PdfRasterizer::page on `MedicalDocumentStore::absolutePath` (the 07-06 scan already allows absolutePath in DocumentController); null -> 403. Response `image/jpeg`, the hardened fileResponse headers (nosniff, CSP default-src 'none', inline disposition with a generic filename `page-<n>.jpg`), and `Cache-Control: no-store, private` from NoStoreDynamicResponses (do not add a cache exemption; research WR-05 consistency). Reads write the usual health read audit row like `file` does (ids only).
