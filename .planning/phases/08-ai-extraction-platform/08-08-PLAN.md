## Contracts this plan creates

- `PdfRasterizer` (final): `pageCount(string $absPdf): int` (pdfinfo, timeout `ai.pdf.info_timeout`, parse `Pages:`; any failure -> 0); `page(string $absPdf, int $page): ?string` (1-based; page > count or < 1 -> null; `pdftoppm -f n -l n -singlefile -jpeg -jpegopt quality=82 -scale-to <ai.pdf.scale> <pdf> <tmpbase>` into a private temp dir that is removed before returning the bytes); `pages(string $absPdf, string $dir, int $max): array{written: list<string>, total: int}` (writes `page-1.jpg .. page-k.jpg`, k = min(total, max)). Every spawn: argv array `['sh', '-c', 'ulimit -v '.$kb.'; exec "$@"', 'sh', 'pdftoppm', ...]`, Process timeout `ai.pdf.timeout`, output discarded, group kill on timeout like CodexRunner. Only file paths generated by the app are passed.
- `WorkDir` (final): `create(): self` makes `<ai.work_dir>/<ulid>` mode 0700 plus `tmp/` 0700; `path()`, `file(string $name): string` (name must match `^[a-z0-9.-]{1,40}$`), `put(string $name, string $bytes)`, `cleanup()` (recursive delete, idempotent); `static sweepStale(int $minutes = 30): int` removes dirs older than the age.
- `Preflight` (final): `envKeysClean(): bool` (none of `ai.forbidden_env` set to a non-empty value via getenv/$_ENV/$_SERVER); `problems(): list<string>` returning codes from: `forbidden_env`, `app_key_present`, `binary_missing`, `version_mismatch` (runs `codex --version` through a short Process with env -i, compares to `ai.codex.version`), `codex_home_unwritable`, `codex_home_in_tmp`, `setsid_missing`, `env_missing`, `retry_after_too_small` (`config('queue.connections.database.retry_after') <= ai.timeouts.job + 60`), `work_dir_unwritable`. No variable values are ever printed.
- `ai:preflight` (AiPreflight command): prints "AI preflight OK" and exits 0, or one line per problem code and exits 1.
- `MedicalFileFixtures::pdfPages(int $n): string`: a valid minimal PDF with n pages (hand-built objects with correct xref offsets) that poppler renders.
</context>
