## Contracts this plan creates

- `VisitQuery::create(Viewer, MedicalSubject, array $data, string $source = 'manual')`, same for Medication, Allergy, Vaccination (Vaccination threads `$source` through its private insert; markGiven keeps 'manual'). `$source` must be 'manual' or 'ai' (InvalidArgumentException otherwise, content-free message). verified_at stays null on create.
- `XQuery::verify(Viewer, MedicalSubject, string $id): bool` (Vaccination takes its public id): one UPDATE `SET verified_at = now(), verified_by = <viewer user id> WHERE id = ? AND subject_id = ? AND subject_id IN (Visibility Edit scope) AND source = 'ai' AND verified_at IS NULL`; returns true when a row changed. Idempotent: a second call returns false and changes nothing.
- `XRequest::fieldRules(): array` (public static) holds the exact current field rules (including ValidUtf8 and length caps); `rules()` returns `self::fieldRules()` (plus any request-only keys). `messages()` likewise exposed as `fieldMessages()` if it exists. The accept path in 08-15 validates with `Validator::make($values, XRequest::fieldRules(), XRequest::fieldMessages())`.
