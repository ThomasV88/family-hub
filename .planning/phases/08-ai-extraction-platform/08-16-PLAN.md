## Component contracts

- Props from PersonPage `ai` (08-13): `{canRun, available, noticeAcknowledged, statuses: {[docId]: {status, extractionId, readyExtractionId, cancelReason, pagesRead, pagesTotal, entryCount?, pending?}}}`.
- `AiStatusTag` props `{status, cancelReason?, entryCount?}` -> UI-SPEC Color table: queued Clock "Waiting for AI", running Loader (static under reduced motion, aria-hidden) "AI is reading", ready Check success "Suggestions ready" or neutral "Nothing to suggest" when entryCount 0, failed CircleX danger, cancelled Ban, cancelled+consent Bot "Stopped: AI is off", superseded Layers. Tags wrap, never truncate.
- `useAiStatus(personId, initialStatuses)` returns reactive `statuses`, `failedPolls`, `stoppedLongWait`; polls `route('health.people.ai.status', person)` via securityFetch only while any status is queued/running: 5 s, 15 s after 2 min, pause on `document.hidden`, resume on visibilitychange, stop on all-terminal or after 15 min (`stoppedLongWait`); 423 -> handleHealthRefusal and stop; error keeps last state, three consecutive errors set `failedPolls`. Exposes `refresh()` (used after run/cancel). No storage of any kind.
- `RunAiControl` props `{personId, document, ai, consentOn}`; emits nothing to storage. States (Screen 1/2): hidden when !canRun (view-only sees only AiStatusTag in the panel); no run -> secondary "Run AI" (Sparkles) + permanent sends_line (aria-describedby); consent off -> aria-disabled button + consent_off_line with link "Go to person header" focusing the AiConsentControl switch; !available -> aria-disabled + unavailable_line; HEIC -> aria-disabled + heic_line; queued/running -> secondary "Cancel run" (Ban) + tag + wait_detail, aria-busy on the block; ready -> primary "Review suggestions" link (`health.documents.ai.review`) + ghost "Run AI again" (opens UiConfirmDialog rerun_* when pending > 0, default focus "Keep current suggestions"); failed -> failed_detail + "Run AI again" (and "Review suggestions" when readyExtractionId still exists); cancelled -> detail + "Run AI"; pagesRead < pagesTotal -> pages_read plural line. Run flow: if !noticeAcknowledged open AiNoticeDialog (title, body, primary "Run AI", secondary "Keep document private" with default focus, Esc/backdrop = cancel) and send `{acknowledged: true}` on confirm; POST run via securityFetch; 202 -> toast started_toast, refresh(), focus to "Cancel run"; 409 consent_off -> switch to consent-off state without an error alert; 409 unavailable/unsupported -> respective line; 409 active -> refresh(); other failure -> UiAlert danger queue_failed (role=alert once). Cancel: POST cancel, toast cancelled_toast, status stays "AI is reading" until the poll reports cancelled. Single polite role=status region announces only transitions (announce_* keys). All model-free: no proposal content is ever rendered here.
