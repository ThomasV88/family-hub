- `CodexRequest` (final readonly): workDir, schemaPath, resultPath, list<string> images (absolute paths inside workDir), prompt, ?model.
- `ProcessResult` (final readonly): exitCode ?int, timedOut, idleTimedOut, aborted, outputCapped, authSignature (bools), durationMs int. No string field. Docblock: "Never add output text here."
- `LoginState` (string enum): logged_in, logged_out, wrong_mode, unknown.
- `CodexRunner` (final): `exec(CodexRequest $r, ?Closure $shouldAbort = null): ProcessResult`; `loginStatus(): LoginState`. Command array exactly: `/usr/bin/env -i PATH=<dir of binary>:/usr/bin:/bin HOME=<home> CODEX_HOME=<home> LANG=C.UTF-8 TMPDIR=<workDir>/tmp /usr/bin/setsid <binary> exec --sandbox read-only --ephemeral --skip-git-repo-check --ignore-user-config --ignore-rules --color never --json --output-schema <schemaPath> -o <resultPath> [-m <model>] -c web_search="disabled" -c features.shell_tool=false -c features.apps=false -c forced_login_method="chatgpt" -c history.persistence="none" -c analytics.enabled=false -c check_for_update_on_startup=false --disable memories -i <img1,img2,...>` with NO positional prompt (prompt via setInput). cwd = workDir; `<workDir>/tmp` created 0700 before spawn. Loop every 250 ms: count incremental stdout/stderr bytes; scan only a bounded rolling window (last 8 KiB) of stderr and of JSONL `error`/`turn.failed` lines for `auth_failure_patterns` (case-insensitive) to set authSignature, then drop the window; kill group on cap overflow, `$shouldAbort()` true (called at most every `abort_check_seconds`), or ProcessTimedOutException (both timeout kinds). Group kill = `posix_kill(-$pid, SIGKILL)` then `$p->stop(0, SIGKILL)`. Refuse (throw content-free `RuntimeException('ai runner unavailable')`) when /usr/bin/env or /usr/bin/setsid is missing. `loginStatus()`: same env/setsid wrapper, args `login status`, timeout `timeouts.login`; exit 0 and stdout contains 'Logged in using ChatGPT' -> logged_in; exit 0 otherwise -> wrong_mode; exit 1 with 'Not logged in' -> logged_out; anything else -> unknown.
- `FakeCodex` (tests/Support, final): static constructors returning a 0700 temp script path: `succeeding(string $json)`, `invalidJson()`, `emptyOutput()` (creates empty -o, exit 1), `exitZeroNoFile()`, `failing(int $code, string $stderr)`, `hanging()`, `silent()`, `forking(string $pidFile)`, `flooding(string $stream)`, `recording(string $file, ?string $json = null)` (writes argv one per line, `env`, `pwd`, `ls -A`, stdin to $file), `loginStatus(int $exit, string $text)`, `echoing(string $canary)` (writes the canary to stdout, stderr and -o). Scripts parse `-o` from "$@" like the research's minimal fake.
