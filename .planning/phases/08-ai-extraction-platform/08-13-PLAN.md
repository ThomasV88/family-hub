## Contracts

- Routes (no route model binding, no whereUuid): `POST /health/people/{person}/documents/{document}/ai` `health.documents.ai.run` (`access:module,health,edit`, `throttle:10,1,health.documents.ai.run`); `POST /health/people/{person}/ai/{extraction}/cancel` `health.ai.cancel` (edit, `throttle:30,1,health.ai.cancel`); `GET /health/people/{person}/ai-status` `health.people.ai.status` (view, `throttle:60,1,health.people.ai.status`). All JSON.
- `AiRunRequest` (authorize first: findVisible Edit, false on null -> identical 403 before validation); body `acknowledged` optional boolean.
- `AiRunQuery::start(Viewer, MedicalSubject, string $documentId, User $user, bool $acknowledged): StartResult` in one DB transaction: lock the subject row `FOR SHARE` through the Visibility Edit scope; document via DocumentQuery::find(Edit) (null -> denied); kind not pdf/image -> `unsupported`; `AiConsent::allows` false -> `consent_off`; `AgentHealth::runnable()` false -> `unavailable`; no `ai_notice_acks` row and not acknowledged -> `notice_required`; audit `MedicalAiRunRequested` {subject, document} first; insert extraction (status queued, agent from AgentRegistry::primary()->key(), model NULL, schema/prompt versions, started_by) catching SQLSTATE 23505 on the active-run index -> `active` with the existing id; insert ai_calls (queued, model NULL: set once at finish by the job or by cancel); upsert ack when acknowledged. `App\Medical\Ai\StartResult` (final readonly): `outcome` (queued|active|consent_off|unavailable|unsupported|notice_required|denied) and `?string extractionId`.
- Controller run: denied -> abort 403; queued -> dispatch `RunExtractionJob::dispatch($id)->afterCommit()` and 202 `{status: 'queued', extractionId}`; others -> 409 `{reason, extractionId?}`.
- `AiRunQuery::cancel(Viewer, MedicalSubject, string $extractionId): ?array{status}`: scoped Edit lookup (null -> 403); queued -> UPDATE to cancelled(user) WHERE status='queued' + ai_calls cancelled (both set model 'default' once, as no agent ran) + audit MedicalAiRunFinished status cancelled; running -> set cancel_requested_at; any other state -> current status (idempotent 200).
- `AiRunQuery::statusMap(Viewer, MedicalSubject): array` via one scoped query (membership predicate) over medical_ai_extractions: per document the newest non-superseded run -> `{status, extractionId, cancelReason, pagesRead, pagesTotal, readyExtractionId}` plus, for Edit viewers only, `{entryCount, pending}` of the ready extraction (pending = entry_count minus decision rows). Status route returns `{documents: map, available: AgentHealth::runnable()}`.
- PersonPage gains prop `ai`: `{canRun: person.canEdit, available, noticeAcknowledged, statuses: statusMap}` (statuses for view-only viewers omit counts). No proposal content in page props.
- zz_ai.php: `visible` seeds one ready extraction (payload with one visit and one medication whose fields contain MedicalPrivacy::CANARY) on the visible person's document and a queued one on a second document; `hidden` seeds the same for the hidden person; `params` `extraction` => visible ready id; `hiddenParams` `extraction` => hidden ready id; `payloads` `health.documents.ai.run` => ['acknowledged' => true], `health.ai.cancel` => [].
