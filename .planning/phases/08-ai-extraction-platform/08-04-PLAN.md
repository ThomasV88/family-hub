## Schema (exact; names are final for later plans)

- `medical_documents`: add `UNIQUE (id, subject_id)` (additive).
- `medical_ai_extractions`: id uuid PK (Str::uuid v4); subject_id uuid FK medical_subjects CASCADE; document_id uuid with composite FK (document_id, subject_id) -> medical_documents (id, subject_id) ON DELETE CASCADE; status varchar(12) CHECK in (queued, running, ready, failed, cancelled, superseded); cancel_reason varchar(8) null CHECK in (user, consent, access); failure_code varchar(24) null; agent varchar(20) default 'codex'; model varchar(60) null; schema_version smallint; prompt_version smallint; started_by bigint (plain); payload jsonb null; entry_count smallint null; pages_read smallint null; pages_total smallint null; cancel_requested_at, queued_at (default now()), started_at, finished_at timestamptz; timestamps. CHECKs: (payload IS NOT NULL) = (status IN ('ready','superseded')); (cancel_reason IS NOT NULL) = (status = 'cancelled'); (failure_code IS NOT NULL) = (status = 'failed'). Indexes: partial unique (document_id) WHERE status IN ('queued','running'); partial unique (document_id) WHERE status = 'ready'; (subject_id, document_id, queued_at DESC); partial (status, queued_at) WHERE status IN ('queued','running').
- `medical_ai_decisions`: extraction_id uuid FK CASCADE; entry_key varchar(20); decision varchar(8) CHECK in (accepted, rejected); record_type varchar(12) null CHECK in (visit, medication, allergy, vaccination); record_id varchar(40) null; edited boolean default false; decided_by bigint; decided_at timestamptz default now(); PK (extraction_id, entry_key); CHECK (decision = 'accepted') = (record_id IS NOT NULL).
- `ai_calls`: id bigserial; extraction_id uuid, subject_id uuid, document_id uuid, started_by bigint (plain, no FK: history outlives rows and people); agent varchar(20); model varchar(60) null; attempt smallint default 1; status varchar(10) CHECK in (queued, running, succeeded, failed, cancelled); failure_code varchar(24) null; queued_at timestamptz default now(); started_at, finished_at null; duration_ms integer null. Indexes (queued_at DESC), (subject_id, queued_at DESC), (started_by, queued_at DESC), (status, queued_at DESC). BEFORE UPDATE trigger: identity columns (id, extraction_id, subject_id, document_id, started_by, agent, attempt, queued_at) immutable; status only forward (queued < running < terminal), terminal frozen; started_at, finished_at, duration_ms, failure_code, model may only change from NULL (model is inserted NULL at queue time and set exactly once when the run finishes: the CLI-reported model name if available, else 'default'). BEFORE DELETE row trigger and BEFORE TRUNCATE statement trigger refuse unless `current_setting('ai.prune', true) = 'on'` AND current_user is the table owner. `REVOKE DELETE, TRUNCATE ON ai_calls FROM fh_app`. `ai_calls_prune(months int DEFAULT 12) RETURNS bigint LANGUAGE plpgsql SECURITY DEFINER SET search_path = public, pg_temp` (set_config('ai.prune','on', true); delete rows with queued_at older than the interval; return count); `REVOKE ALL ... FROM PUBLIC; GRANT EXECUTE ... TO fh_app`. Refuse to migrate in production/staging when role fh_app is missing (audit migration pattern); skip REVOKE/GRANT when fh_app is absent in local/testing exactly as the audit migration does.
- `ai_agent_status`: agent varchar(20) PK; login_state varchar(12) CHECK in (logged_in, logged_out, wrong_mode, unknown) default 'unknown'; checked_at, last_success_at, last_auth_failure_at timestamptz null; updated_at.
- `ai_notice_acks`: user_id bigint PK FK users CASCADE; acknowledged_at timestamptz default now().
- Models: MedicalAiExtraction (uuid key, casts payload array, dates), MedicalAiDecision (composite key, no incrementing, read via query builder mostly), AiCall, AiAgentStatus (string key). No `$fillable` of status on client paths (all writes go through Query classes in later plans).
