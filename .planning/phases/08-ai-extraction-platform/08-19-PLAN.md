## Contracts

- `EntryEditForm` props `{type, fields, errors?, saving}`; emits `save(values)`, `cancel`, `dirty-change(bool)`. Fields per type use the same keys and labels as the 07 panels: visit (visited_on date, doctor, specialty_key select from the taxonomy, specialty_other when other, diagnosis, notes; no Documents section, the visit is linked on save by the server), medication (name, dose, schedule, started_on, ended_on, notes), allergy (substance, reaction, severity select), vaccination (vaccine, given_on, next_due_on, notes). Server errors map to the fields (aria-invalid, aria-describedby error text) using the 07 message style; the allergy severity message is `health.ai.review.needs_severity`. Enter in inputs does not submit; Esc cancels (dirty confirm applies). Footer: primary "Save {record}" (save_<type>), secondary "Cancel" (cancel_edit).
- SuggestionEntry: on `edit-requested` expand the form (first field focused, or the first flagged field when errors exist); Save posts `{values}` to accept; 200 -> accepted state + edited_detail line + focus rules of Accept; 422 -> errors back into the form; 409 superseded -> banner; failure -> action_failed alert. Cancel clean -> collapse, focus Edit; cancel dirty -> UiConfirmDialog discard_title with "Discard edit" (danger) and "Keep editing" (default focus).
- AiReview page: holds `editingKey`; opening another entry while the current one is clean switches silently; while dirty, the discard confirm runs first. A layout or pane switch keeps the form mounted.
