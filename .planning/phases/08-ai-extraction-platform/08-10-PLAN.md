## Contracts

- `AgentInput` (final readonly, app/Medical/Ai/Agents/AgentInput.php): WorkDir, list<string> image names.
- `Agent` interface: `key(): string` ('codex'), `modelLabel(): string` (config model or 'default'), `extract(AgentInput $in, ?Closure $shouldAbort = null): AgentOutcome`, `loginStatus(): LoginState`.
- `AgentOutcome` (final readonly): `ok`, `?array payload`, `?int entryCount`, `?FailureCode failure`, `bool aborted`, `int durationMs`.
- `CodexAgent::extract`: writes `schema.json` (copy of ExtractionSchema::path()) into the work dir, builds a CodexRequest (resultPath `<dir>/result.json`, images, PromptBuilder::build(), model), calls CodexRunner::exec, then maps in this order: aborted -> outcome aborted (no failure code; caller decides cancelled); timedOut -> timeout; idleTimedOut -> idle_timeout; outputCapped -> output_too_large; authSignature and no valid file -> auth; otherwise ExtractionValidator::fromFile(result.json) (exit code is ignored for success; a valid file with exit 1 still counts as success only if the validator accepts it — documented), with non-success and exit != 0 and no file -> cli_error, empty file -> no_output.
- `AgentRegistry` (final, singleton binding in AppServiceProvider): `agents(): list<Agent>` = [CodexAgent], `primary(): Agent`, `find(string $key): ?Agent`. Docblock: "Phase 9 adds Copilot, order and fallback here."
- `AgentHealth` (final): `recordCheck(string $agent, LoginState $state)` upserts login_state + checked_at; `recordAuthFailure(string $agent)` sets last_auth_failure_at; `recordSuccess(string $agent)` sets last_success_at; `display(string $agent = 'codex'): string` -> 'unknown' when no row or checked_at null; 'not_responding' when checked_at older than `ai.login_stale_minutes`; 'expired' when login_state in (logged_out, wrong_mode) or last_auth_failure_at > coalesce(last_success_at, -infinity) and > checked state time; else 'logged_in'; `runnable(): bool` = display not in (expired, not_responding) (PROVISIONAL: 'unknown' is runnable, matching UI-SPEC "not known to be expired"); `snapshot(): array{state, checkedAt}` for the admin page.
- `CheckLoginJob` (implements ShouldQueue, ShouldBeUnique): constructor sets `onConnection('database')` and `onQueue(config('ai.queue'))` (never runs inline under phpunit's sync default), `uniqueFor = 300`, `tries = 1`, `handle(AgentRegistry, AgentHealth)`: for each agent recordCheck(key, loginStatus()); never stores text.
