## Adapter contract (App\Security\Passkeys\PasskeyCeremony; resolves package actions from the container)

- `registrationOptions(User $u): array` -> GenerateRegistrationOptions, stores `WebAuthn::toJson` in session `passkey.registration_options`, returns `WebAuthn::toBrowserArray`.
- `register(User $u, PasskeyRegistrationRequest $r, string $name): ?Passkey` -> StorePasskey; any Throwable -> null (log exception class only).
- `verificationOptions(User $u): array` -> GenerateVerificationOptions($u) (allowCredentials = this user's passkeys), session `passkey.verification_options`.
- `verify(User $u, PasskeyVerificationRequest $r): bool` -> VerifyPasskey(credential, options, $u); any Throwable -> false.
Responses: options -> `{"options": {...}}`; registration success -> 201 `{"passkey": {id, name, authenticator, createdAt, lastUsedAt}}`; challenge success -> guard login with `login.remember`, session regenerate, `SensitiveSession::confirm()`, forget login.* keys, 200 `{"redirect": SafeIntended::pull()}`; reauth success -> `confirm()`, audit ReauthConfirmed {method: passkey}, body flag `mode` = page -> `{"redirect": SafeIntended::pull()}`, dialog -> `{"confirmed": true}`; any failure -> 422 `{"error": "passkey_failed"}` plus audit SecondFactorFailed {method: passkey, context: login|reauth}.
</context>

|----------|-------------|
