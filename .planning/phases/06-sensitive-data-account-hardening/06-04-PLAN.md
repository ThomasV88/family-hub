## Gate contract (SensitiveGate::check, called only for Module::sensitive() after an allow decision)

1. `SecondFactorPolicy::mustEnrol($user)`: JSON caller -> 423 `{"error":"second_factor_required"}`; otherwise remember the intended address (GET: full URL; non-GET: previous()) and redirect to `/settings/security` with flash status `second_factor_required` (303 for non-GET, 302 for GET). Comes before the idle check.
2. `! SensitiveSession::fresh()`:
   - passive (header `Purpose: prefetch` or `X-Fh-Passive: 1`): 423 `{"error":"reauth_required"}`, nothing stored, nothing slid.
   - JSON caller (`expectsJson()` and no `X-Inertia`) or non-navigational load (`Sec-Fetch-Mode` present, not `navigate`, no `X-Inertia`): remember previous() as intended, flash status `reauth_interrupted` when the method is not GET/HEAD, answer 423 `{"error":"reauth_required"}` (no body for non-JSON).
   - otherwise (Inertia or full navigation): GET -> remember full URL, 302 `/confirm-access`; non-GET -> remember previous(), flash `reauth_interrupted`, 303 `/confirm-access`.
3. Fresh: unless passive, `SensitiveSession::touch()`. Return null (continue).
"JSON caller" means `$request->expectsJson() && ! $request->header('X-Inertia')`. "Remember" always goes through `SafeIntended::remember`.

## Confirm endpoints (routes/web/reauth.php)

- `GET /confirm-access` name `confirm-access`, `access:authenticated` -> Inertia `Auth/ConfirmAccess` props: `methods` {password: user.password_set, totp: user.hasEnabledTwoFactorAuthentication(), passkey: config security.passkeys_enabled && user has passkeys, google: user.google_id !== null}, `minutes` (idle_seconds / 60), `interrupted` (flash status reauth_interrupted). No other data.
- `POST /confirm-access` name `confirm-access.store`, `access:authenticated` + `throttle:reauth`: exactly one of `password` or `code` (strings; arrays or both -> 422; `recovery_code` not accepted). Password: only when password_set, `Hash::check`. Code: only when TOTP confirmed, verify with `Laravel\Fortify\Contracts\TwoFactorAuthenticationProvider::verify(decrypt secret, code)` (replay-protected). Success: `SensitiveSession::confirm()`, audit `ReauthConfirmed` meta method password|totp; JSON caller -> 200 `{"confirmed":true}` (intended untouched); otherwise 303 to `SafeIntended::pull()`. Failure: audit `SecondFactorFailed` meta {method, context: reauth}; JSON -> 422 `{"errors":{"password"|"code": "reauth.error.password"|"twofactor.error.code"}}`; otherwise back with the same error keys.
- `POST /confirm-access/sign-in-again` name `confirm-access.restart`, `access:authenticated`: keeps `url.intended`, clears the sensitive keys (new `SensitiveSession::clear()`), logs out the web guard, regenerates the session id (not invalidate), 303 to /login.
