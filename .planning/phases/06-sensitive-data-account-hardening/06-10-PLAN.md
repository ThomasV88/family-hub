## Behaviour contract

- `GET /confirm-access/google` name `confirm-access.google`, `access:authenticated`, `throttle:10,1`: 404 when the member has no google_id or Google is disabled; otherwise put session `reauth.google` = {user: id, at: now} and return the Socialite redirect with extra parameters `prompt=select_account` and `max_age=0` [ASSUMED: Google's honouring of max_age/prompt is unverified; 06-13 checks it with the owner].
- `/auth/google/callback` changes from `access:guest` to `access:public`; the controller decides:
  1. Signed in and `reauth.google` pulled from the session, fresh (<= 600 s) and for this user: read the Socialite identity WITHOUT calling GoogleLoginService::resolve (no linking, no account creation). Identity id equals the member's google_id -> `SensitiveSession::confirm()`, audit ReauthConfirmed {method: google}, 303 to `SafeIntended::pull()`. Otherwise audit SecondFactorFailed {method: google, context: reauth} and redirect /confirm-access with status `google_reauth_failed`.
  2. Signed in without the flag -> redirect '/' (what the guest rule did before).
  3. Guest: existing flow. When the resolved user `hasSecondFactor()`: put login.id, login.remember = false, login.at = now and redirect to route `two-factor.login` (no Auth::login; the Login event and login_success row fire only when the challenge passes). Otherwise Auth::login, session regenerate, `SensitiveSession::confirm()`, redirect `SafeIntended::pull()` ('/' fallback; keep the welcome toast for 'created').
- password_set: InviteService::accept sets password_set false when the account is created through Google; ResetUserPassword sets it true. Everything else keeps the default true.
- ConfirmAccess.vue: when `methods.google`, put a full-page link styled as a secondary button `reauth.google` (href /confirm-access/google, not an Inertia link) in ReauthForm's `alternatives` slot; show a danger alert `reauth.google_failed` for flash status google_reauth_failed. For an account with no password and no factor, the Google button is shown alongside `reauth.no_method` and "Sign in again".
</context>
