## Contracts (03-10 extends the push side; Phase 4 adds kinds)

remind_at maintenance (TaskReminderObserver::saving, registered with Task::observe in AppServiceProvider::boot; Task.php is not edited): recompute only when the task is new or one of due_date, due_time, remind_before_minutes, timezone, status, completed_at, skipped_at is dirty. remind_at = null when status is done, completed_at or skipped_at is set, due_date is null or remind_before_minutes is null; otherwise ReminderTimeCalculator::remindAt(...); a computed instant earlier than now() becomes null (no retroactive reminders for tasks created or moved into the past). Consumers clear remind_at with a query update (Task::whereKey($id)->update(['remind_at' => null])), which bypasses the observer.

notification_outbox: id; kind varchar(40); user_id FK users cascadeOnDelete; channel varchar(16) CHECK in (mail, push); subject_type varchar(40); subject_id bigint; dedupe_key varchar(191) UNIQUE; payload jsonb (ids and the occurrence timestamp only, never titles or notes); status varchar(16) default 'pending' CHECK in (pending, queued, sending, sent, failed, skipped); attempts smallint default 0; available_at timestamptz; sent_at timestamptz null; last_error varchar(255) null (exception class basename only); timestamps. Index (status, available_at).
notification_preferences: id; user_id FK cascadeOnDelete; channel varchar(16) CHECK in (mail, push); enabled boolean; timestamps; UNIQUE (user_id, channel).

App\Notifications\NotificationPreferences: enabled(User, string $channel): bool (no row: mail true, push false); set(User, string $channel, bool): void (upsert).
App\Notifications\Outbox\OutboxWriter::enqueue(string $kind, User $user, string $channel, string $subjectType, int $subjectId, string $dedupeKey, array $payload): bool (insertOrIgnore on dedupe_key; true when a row was inserted).
interface App\Notifications\Outbox\OutboxHandler: kind(): string; stillRelevant(OutboxItem, User): bool; sendMail(OutboxItem, User): void; pushMessage(OutboxItem, User): array{title: string, url: string}.
App\Notifications\Outbox\OutboxHandlers: for(string $kind): OutboxHandler (registry array kind => class, resolved from the container; unknown kind throws). TaskReminderHandler kind 'task_reminder': stillRelevant = task still exists, is open, the user holds todo >= view and Task::visibleTo($user) finds it; sendMail = $user->notifyNow(new TaskReminderNotification(...)); pushMessage title = trans('notifications.reminder_title', ['title' => mb_strimwidth(title, 0, 80, '…')], locale), url = '/todo?task='.id.
App\Tasks\ReminderRecipients::for(Task): list<User>: Personal -> [creator]; otherwise [assignee ?? creator]; then filter users holding todo >= view whom Task::visibleTo finds.
Dedupe key: "task_reminder:{taskId}:{remindAtUnix}:{userId}:{channel}". Payload: {"task_id": id, "remind_at": unix}.

Commands: reminders:enqueue (EnqueueReminders), outbox:dispatch (DispatchOutbox), outbox:prune (PruneOutbox). Scheduled in routes/console.php: reminders:enqueue and outbox:dispatch everyMinute()->withoutOverlapping() with names reminders-enqueue / outbox-dispatch; outbox:prune daily.
SendOutboxItem (ShouldQueue): public $tries = 1 (retry state lives in the outbox row so it is visible and survives queue flushes; discretion recorded here); backoff schedule in the row: after attempt n set available_at = now + [60, 300, 900, 3600][n-1] seconds and status pending; after attempt 5 status failed.
