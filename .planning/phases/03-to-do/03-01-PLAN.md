## Format facts (from the codebase)

- lang/*.json is nested JSON consumed by vue-i18n (not ICU). Plurals are pipe-separated segments: en has 2 segments (one | other), sk and pl have 4 segments in the order one | few | many | other (see FORM_ORDER in resources/js/i18n.js and the auth.error.throttle test in tests/js/i18n-phase2.test.js). The implicit `{n}` and `{count}` params are available in pipe plurals.
- vue-i18n special characters: a literal `@` must be written `{'@'}`, a literal `|` is a plural separator, `{` starts a placeholder. None of the Phase 3 strings may contain an exclamation mark (tone rule, existing tests).
- Laravel server-side group files use `:param` placeholders (lang/en/mail.php pattern). A JSON key like `notifications.reminder_title` would NOT be found by `trans()` because the JSON is nested; server strings therefore live in lang/*/notifications.php.
</context>
