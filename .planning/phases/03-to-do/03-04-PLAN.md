## Interfaces this plan creates (consumed by 03-07 and 03-09; keep exactly)

- enum App\Recurrence\RecurrenceMode: string { Schedule = 'schedule'; Completion = 'completion' }
- final class App\Recurrence\RecurrencePattern (readonly): kind ('daily'|'weekly'|'monthly_day'|'monthly_last'|'custom'), interval int 1..99 (daily/weekly/monthly use 1 unless custom), unit ('day'|'week'|'month') only for custom, weekdays list<string> of MO,TU,WE,TH,FR,SA,SU only for weekly (non-empty, unique, ordered MO..SU), monthDay int 1..31 only for monthly_day. Static fromArray(array) validates and throws InvalidArgumentException; toArray() returns the same keys (this is the shape the panel posts and receives as `recurrence`).
- final class App\Recurrence\RuleBuilder: static toRrule(RecurrencePattern): string (no DTSTART; daily "FREQ=DAILY;INTERVAL=1"; weekly "FREQ=WEEKLY;INTERVAL=1;BYDAY=MO,WE"; monthly_day N<=28 "FREQ=MONTHLY;INTERVAL=1;BYMONTHDAY=N", N in 29..31 "FREQ=MONTHLY;INTERVAL=1;BYMONTHDAY=28,..,N;BYSETPOS=-1"; monthly_last "FREQ=MONTHLY;INTERVAL=1;BYMONTHDAY=-1"; custom "FREQ=DAILY|WEEKLY|MONTHLY;INTERVAL=n" (custom monthly anchors on the due date's day via BYMONTHDAY clamp set like monthly_day)); static fromRrule(string): RecurrencePattern (exact inverse for strings it produced; anything else throws InvalidArgumentException: allowlist, max 255 chars).
- interface App\Recurrence\RecurrenceEngine: next(string $rrule, CarbonImmutable $anchorLocal, RecurrenceMode $mode, ?CarbonImmutable $completedAtLocal, string $timezone, CarbonImmutable $now): ?CarbonImmutable. $anchorLocal = the occurrence's scheduled local due (date + time, or date at 00:00 for date-only) in $timezone. Returns the next scheduled local wall-clock datetime in $timezone, or null if none within the cap. Schedule mode: first occurrence strictly after $anchorLocal AND strictly after $now (local). Completion mode: rebuild the series with DTSTART = completion local date at the anchor's local time-of-day and return the first occurrence strictly after the completion instant (pure interval rules: completion date + interval; weekly/monthly rules keep BYDAY/BYMONTHDAY). Iteration cap: 1000 occurrences or 10 years, whichever first.
- final class App\Recurrence\LocalTime: static at(string $date, ?string $time, string $tz): CarbonImmutable (local wall clock; nonexistent spring-forward times move forward, ambiguous fall-back times take the first instant; pinned by tests).
- final class App\Tasks\ReminderTimeCalculator: remindAt(?string $dueDate, ?string $dueTime, string $timezone, ?int $beforeMinutes): ?CarbonImmutable (UTC). null date or null beforeMinutes -> null. Base = local due (date-only -> 08:00 local). 0 -> base; 15 or 60 -> base instant minus that many real minutes (only valid with a due time; with date-only throws InvalidArgumentException, the request layer prevents it); 1440 -> same local wall-clock one calendar day earlier (date-only: previous day 08:00).
</context>
