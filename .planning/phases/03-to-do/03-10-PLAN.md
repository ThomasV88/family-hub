## Contracts (03-11 builds the settings UI on these routes)

push_subscriptions: id; user_id FK users cascadeOnDelete; endpoint text; endpoint_hash char(64) UNIQUE (sha256 of endpoint); p256dh text and auth text with the Laravel 'encrypted' cast; content_encoding varchar(16) default 'aes128gcm'; label varchar(100) null (App\Support\UserAgentLabel of the request); last_success_at timestamptz null; timestamps. Index user_id.
config/push.php: subject => env('VAPID_SUBJECT'), public_key => env('VAPID_PUBLIC_KEY'), private_key => env('VAPID_PRIVATE_KEY'). "Configured" means all three are non-empty.
interface App\Push\PushSender: send(PushSubscription $subscription, array $message): PushResult. enum App\Push\PushResult: Success, Expired, Failed. WebPushSender uses Minishlink\WebPush\WebPush with the VAPID config, Subscription::create([endpoint, publicKey => p256dh, authToken => auth, contentEncoding]), sendOneNotification(..., json_encode($message), ['TTL' => 3600, 'urgency' => 'normal']); report isSuccess -> Success, isSubscriptionExpired -> Expired, else Failed. Never logs the payload or keys.
Routes (routes/web/notifications.php, all access:authenticated since notifications are per user and Phase 4 reuses them; JSON responses for fetch from push.js):
- POST /settings/notifications/push -> PushSubscriptionController@store, name settings.notifications.push.store, throttle:20,1; body {endpoint, keys: {p256dh, auth}, contentEncoding?}; upsert by endpoint_hash rebinding to the current user; 201 {ok: true}
- DELETE /settings/notifications/push -> @destroy, name settings.notifications.push.destroy; body {endpoint}; deletes only the current user's row; 204
- POST /settings/notifications/push/test -> @test, name settings.notifications.push.test, throttle:5,1; 422 {error: 'none'} when the user has no subscription, 503 {error: 'not_configured'} when VAPID is not configured, else sends notifications.test_title (user locale) with url '/settings/notifications' to each subscription and returns 200 {sent: n}
Endpoint validation (PushEndpointRule): https scheme only, no userinfo, no explicit port, max 2048 chars, host equal to or a subdomain of one of fcm.googleapis.com, updates.push.services.mozilla.com, push.apple.com, notify.windows.com; IP literals rejected. p256dh must base64url-decode to 65 bytes, auth to 16 bytes. Per-user cap 10: storing an 11th deletes the user's least recently updated subscription.
Matrix rows (guest 302 for all; data uses endpoint https://fcm.googleapis.com/fcm/send/matrix-row and valid-length keys): store -> 201 for admin, parent, child, grandparent, guestPreset, noGrants; destroy -> 204 for the same six; test -> 422 for the same six (no subscription of their own).
Message for a reminder: {title: handler->pushMessage()['title'], url: handler->pushMessage()['url'], tag: substr(sha1(dedupe_key), 0, 16)}; no body, never notes.

| Boundary | Description |

| browser -> subscription endpoint | client supplies a URL the server will later POST to |
| worker -> push services | task titles leave the server to third-party push services |
| service worker -> navigation | push payload controls the URL opened on click |
