## Contract

Request fields (Store and Update): visibility in personal|family|selected (default family on create); member_ids array of integers, required with at least one entry when visibility = selected (error key todo.error.selected_none), each id must hold todo >= view (HasTodoAccess, error todo.error.assignee), ignored otherwise.
TaskService invariants (in one transaction): Personal -> assignee_id forced to the creator, task_members detached; Selected -> task_members synced to member_ids plus the creator and the assignee if set; assignee must be the creator or in member_ids else validation error assignee_id = todo.error.assignee; Family -> task_members detached. On update, visibility and member_ids are applied only when TaskAccess::canChangeVisibility (creator); a non-creator editor sending them gets 403 (not silently ignored), so the UI must not send them.
Board props: tasks[].memberIds already exists (03-03); keep it.
