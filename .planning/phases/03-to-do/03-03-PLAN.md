tasks table (one migration, all Phase 3 columns so later plans add no task columns):
id bigint PK; series_id uuid null; title varchar(200); notes text null; status varchar(16) default 'todo' CHECK in (todo,in_progress,done); visibility varchar(16) default 'family' CHECK in (personal,family,selected); creator_id FK users restrictOnDelete; assignee_id FK users nullOnDelete null; due_date date null; due_time time(0) null; timezone varchar(64) not null; remind_before_minutes integer null default 0 (null = no reminder; CHECK null or in 0,15,60,1440); remind_at timestamptz null; recurrence_rule varchar(255) null; recurrence_mode varchar(16) null CHECK null or in (schedule,completion); completed_at timestamptz null; completed_by FK users nullOnDelete null; skipped_at timestamptz null; timestamps (timestamptz).
Table CHECKs: due_time IS NULL OR due_date IS NOT NULL; recurrence_rule IS NULL OR due_date IS NOT NULL; (recurrence_rule IS NULL) = (recurrence_mode IS NULL).
Indexes: (assignee_id, status), (creator_id), (visibility), partial (remind_at) WHERE remind_at IS NOT NULL, partial UNIQUE (series_id) WHERE series_id IS NOT NULL AND completed_at IS NULL AND skipped_at IS NULL (raw SQL, name tasks_one_open_per_series).
task_members: task_id FK cascadeOnDelete, user_id FK cascadeOnDelete, unique (task_id, user_id), index (user_id). Rows only for visibility=selected.

App\Models\Task: $fillable = title, notes, status, visibility, assignee_id, due_date, due_time, remind_before_minutes, recurrence_rule, recurrence_mode. Never fillable: creator_id, timezone, series_id, remind_at, completed_at, completed_by, skipped_at (set with forceFill by services). Casts: status => App\Tasks\TaskStatus, visibility => App\Tasks\TaskVisibility, due_date => 'date:Y-m-d', remind_at/completed_at/skipped_at => 'immutable_datetime', remind_before_minutes => 'integer'; recurrence_mode stays a string (enum App\Recurrence\RecurrenceMode is created in 03-04). Relations: creator(), assignee() BelongsTo User; members() BelongsToMany User via task_members. Scopes: scopeVisibleTo(Builder, User) exactly as RESEARCH Pattern 5 (creator OR family OR selected with EXISTS on task_members); scopeOpen (completed_at null and skipped_at null). Helper isRecurring(): bool. No is_admin reference anywhere in task code. Later plans do NOT modify app/Models/Task.php.

config/family.php: 'timezone' => env('FAMILY_TIMEZONE', 'Europe/Bratislava'). app.timezone stays UTC.

Board props (TaskController@index, Inertia 'Todo/Index'): timezone (string), today (Y-m-d in the family zone), canEdit (bool, todo edit grant), members (list of {id, name} for users with todo >= view, ordered by name), tasks (list of {id, title, notes, status, visibility, creatorId, assigneeId, dueDate 'Y-m-d'|null, dueTime 'H:i'|null, isRecurring, completedAt ISO|null, memberIds list<int>}). Board query: Task::visibleTo($user) where open OR completed_at >= now()-30 days, excluding skipped, eager-load members:id, no N+1. Member emails are never sent.

Routes (routes/web/todo.php): GET /todo -> TaskController@index, name todo.index, middleware access:module,todo,view. POST /todo/tasks -> TaskController@store, name todo.tasks.store, middleware access:module,todo,edit and throttle:60,1. Store redirects back (303) with session flash_data ['taskId' => id] and toast key 'todo.quick.added'.

StoreTaskRequest (this plan: title only): title required|string|max:200 after trim; error messages map to i18n keys todo.error.title_required and todo.error.title_long. Plan 03-05 extends it with the other fields.
