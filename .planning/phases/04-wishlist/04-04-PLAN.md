## Contract consumed by plan 04-07 (FetchWishImage)

- `new SafeFetcher(?DnsResolver $dns = null, ?IpPolicy $policy = null, ?callable $handler = null, int $maxHops = 3)`; defaults are `SystemDnsResolver` and `PublicIpv4Policy`. No container binding or service provider change is needed.
- `get(string $url, int $maxBytes, string $kind): FetchResult` where `$kind` is `'html'` (Accept text/html, cap normally 512 KiB) or `'image'` (Accept image/*, cap normally 5 MiB). Throws `FetchFailed` (with a short machine `reason` such as `blocked_address`, `bad_url`, `too_large`, `too_many_redirects`, `http_status`, `timeout`, `network`) on every failure; never returns partial data.
- `FetchResult` has `body` (string), `finalUrl` (string), `status` (int), `contentType` (?string, informational only, never trusted).
- `MetaImageExtractor::candidates(string $html, string $baseUrl): list<string>` returns absolute http(s) URLs in priority order, deduplicated, at most 5.
