## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cloudflare -> edge -> nginx | TLS passthrough with PROXY protocol header from the edge |
| CI runner -> server (deploy.sh) | Image tag and files arrive from CI |
| migrate container -> postgres | DDL-capable owner credentials |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-14 | Spoofing | real client IP | mitigate | `set_real_ip_from` limited to edge subnet 10.250.250.0/24; real IP used for logging and throttling only, never authorization |
| T-01-15 | Information disclosure | TLS / headers | mitigate | TLS 1.2+, HSTS, nosniff, CSP `script-src 'self'`, frame-ancestors none, X-Frame-Options DENY via snippet included in every location |
| T-01-16 | Information disclosure | secrets in compose `.env` | mitigate | guard_env_has_no_passwords; secrets only in app.env/migrate.env/secrets/ with mode 0600 (guard_secrets) |
| T-01-17 | Information disclosure | production data in staging | mitigate | guard_reseed checks project name, STACK_ENV, APP_ENV and directory; tested in test-deploy-guards.sh |
| T-01-18 | Tampering | IMAGE_TAG injection | mitigate | guard_inputs regex `^sha-[0-9a-f]{7,40}$` before any use |
| T-01-19 | Elevation of privilege | DDL credentials | mitigate | Owner credentials only in migrate.env, loaded only by the one-shot `migrate` profile service |
| T-01-20 | Information disclosure | debug output | mitigate | APP_DEBUG=false template; smoke-server asserts no stack trace on 404 |
| T-01-21 | Denial of service | other stacks on the VPS | mitigate | No published ports, mem_limit per service, `--remove-orphans` scoped to the project, image prune only by age |
| T-01-22 | Repudiation / recovery | failed migration | mitigate | Encrypted pre-migrate restic snapshot before migrate; `.last-good-tag` rollback for images |
</threat_model>
