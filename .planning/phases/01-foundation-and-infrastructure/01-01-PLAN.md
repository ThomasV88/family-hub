## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package registries / Docker Hub -> build | Third-party code enters the app and images |
| browser -> nginx -> php-fpm | Untrusted HTTP requests (locally only in this plan) |
| nginx -> app:9000 | FastCGI on internal compose network only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SC | Tampering | composer/npm installs, base images | mitigate | Blocking human-verify Task 1 before any install; exact pins for vite-plugin-pwa and laravel-vite-plugin; lockfiles committed; `npm ci` in image builds |
| T-01-01 | Information disclosure | .gitignore / repo | mitigate | .env, app.env, migrate.env, secrets/, cloudflare.ini, *.dump ignored in Task 2 |
| T-01-02 | Spoofing | trustProxies('*') | mitigate | php-fpm port 9000 not published in compose.yaml; only nginx reaches it (accepted assumption A7, enforced by acceptance check that compose publishes only nginx 8080 locally) |
| T-01-03 | Elevation of privilege | DB roles | mitigate | Runtime role fh_app has DML only; DDL only via fh_owner in one-shot migrate runs |
| T-01-04 | Elevation of privilege | containers | mitigate | prod target runs as www-data, dev as uid 1000, no root process serving requests |
| T-01-05 | Information disclosure | nginx | mitigate | dotfiles denied, server_tokens off, X-Powered-By hidden |
</threat_model>
