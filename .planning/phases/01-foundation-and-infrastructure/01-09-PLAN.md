## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server responses -> browser caches (SW Cache Storage, HTTP cache) | Data persisted on shared family devices |
| service worker scope `/` | Worker can intercept every same-origin request |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-43 | Information disclosure | Service worker cache | mitigate | Precache-only worker; build fails on any URL outside the allowlist or any runtime-caching token (check-sw-precache.mjs, unit-tested) |
| T-01-44 | Information disclosure | HTTP cache / bfcache | mitigate | NoStoreDynamicResponses sets `no-store, private` on all dynamic responses (Pest-tested); nginx keeps only hashed assets immutable |
| T-01-45 | Tampering | stale or hijacked worker | mitigate | sw.js served from same origin with `no-cache`; registerType prompt and user-triggered skipWaiting; CSP `worker-src 'self'` (plan 01-04) |
| T-01-46 | Tampering (XSS) | offline.html | mitigate | Static file, no scripts, no external resources |
</threat_model>
