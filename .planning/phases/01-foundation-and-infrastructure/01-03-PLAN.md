## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> POST /heartbeat | Unauthenticated write-triggering request |
| app -> postgres jobs table | Queue payloads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-10 | Denial of service | POST /heartbeat | mitigate | `throttle:6,1` per IP (tested 429), rows older than 7 days pruned in the job, so table size is bounded |
| T-01-11 | Tampering | POST /heartbeat | mitigate | Laravel web-group CSRF (VerifyCsrfToken / XSRF cookie); no request input is persisted (source is hard-coded 'manual') |
| T-01-12 | Information disclosure | Home props | accept | Only timestamps and counts of system checks, no personal data; page is public in Phase 1 by design |
| T-01-13 | Tampering | queue payload | accept | Job payload holds only a fixed source string; jobs table reachable only from app/worker on the internal network |
