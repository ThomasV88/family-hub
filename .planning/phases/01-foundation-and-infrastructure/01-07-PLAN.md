<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> POST /locale | Untrusted locale value |
| request headers -> SetLocale | Untrusted Accept-Language and cookie |
| lang files -> Inertia props -> DOM | Translation strings rendered in the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-33 | Tampering | POST /locale | mitigate | `required|in:sk,pl,en` allowlist validation, CSRF via web group, throttle 30/min |
| T-01-34 | Tampering | locale cookie / Accept-Language -> lang_path | mitigate | Only allowlisted codes reach `lang_path("$locale.json")`; no path built from raw input (prevents path traversal) |
| T-01-35 | Tampering (XSS) | translated strings | mitigate | Vue text interpolation only, no `v-html` with messages; vue-i18n escaping defaults kept |
| T-01-36 | Information disclosure | locale cookie | accept | Holds only a language code; HttpOnly, SameSite=Lax, Secure on servers |
</threat_model>
