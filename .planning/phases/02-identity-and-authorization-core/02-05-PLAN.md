## Contracts this plan defines (plans 06, 07, 08, 09 call them)

- `App\Audit\AuditEvent` (string-backed): login_success, login_failed, lockout, password_reset, admin_created, invite_created, invite_resent, invite_revoked, invite_accepted, permission_changed, session_revoked, session_revoked_all, google_linked, access_denied, health_read, health_write, finance_read, finance_write. Method `group()` maps to the UI filter groups: login (login_success), login_failed (login_failed, lockout), invite (invite_*), permission (permission_changed), session_revoked (session_revoked, session_revoked_all), health (health_*, access_denied with module health), finance (finance_*, access_denied with module finance), account (password_reset, admin_created, google_linked).
- `App\Audit\AuditLogger::record(AuditEvent $event, ?User $actor, array $meta = [], ?User $target = null, ?Module $module = null): void`. Snapshots actor name into actor_label and target name into meta-free target columns; IP from the current request (null in console). Meta allowlist per event (only these keys, scalar values, strings max 120 chars, otherwise throws InvalidArgumentException): permission_changed {from, to}; invite_* {email, preset}; session_revoked {device}; access_denied {level}; all others none. Never accepts typed passwords, tokens, request bodies or record content.
- Model `App\Models\AuditEntry` on table audit_logs: `$timestamps = false`, no update/delete helpers used anywhere (save on an existing row throws LogicException via an `updating`/`deleting` model event guard).
- Session flag: the Login listener stores `session(['auth_remember' => true])` when the Login event has remember true (plan 08 reads it for the "Stays signed in" tag).
