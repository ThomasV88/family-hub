<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> POST /login | Untrusted credentials, brute-force and enumeration attempts |
| Server shell -> family:create-admin | Operator-supplied admin credentials |
| Session cookie / remember cookie | Long-lived bearer tokens on shared family devices |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Spoofing | POST /login brute force | mitigate | named limiter: 5/min per email+IP, 10 per 15 min per email, 30/min per IP; Lockout event; LoginTest asserts throttle |
| T-02-04 | Information Disclosure | login error and timing | mitigate | one error key for unknown email and wrong password; dummy bcrypt hash for unknown users |
| T-02-05 | Spoofing | session fixation | mitigate | Fortify regenerates the session on login; test asserts the id changes |
| T-02-06 | Elevation of Privilege | remember cookie lifetime | mitigate | setRememberDuration(43200), RememberMeTest bounds expiry to 29-31 days; expire_on_close true without remember |
| T-02-07 | Elevation of Privilege | mass assignment of is_admin/google_id | mitigate | not in Fillable; forceFill only in the command and services |
| T-02-08 | Information Disclosure | admin password in shell history | mitigate | password only via `secret()` prompt, never an argument |
| T-02-09 | Tampering | open redirect after login | mitigate | Fortify `redirect()->intended()` with home '/', no `?next=` parameter accepted |
| T-02-10 | Elevation of Privilege | second admin creation | mitigate | command refuses when any admin exists; CreateAdminTest |
</threat_model>
