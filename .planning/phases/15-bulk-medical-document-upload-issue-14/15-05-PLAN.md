<objective>
Expose the batch domain over HTTP with the existing Health conventions: no route model binding, one indistinguishable 403 for every miss, throttles per route, JSON for actions and an Inertia page for the batch (D-06, D-07). Files go through the existing document upload endpoint with an extra `upload_batch_id` field, so the nginx 12 MB body limit on `/health/people/<uuid>/documents`, MedicalDocumentStore sanitising and the per-person cap all apply unchanged.

Routes (all under `access:module,health,...`; `{person}`, `{batch}`, `{item}` resolved through the query classes, never bound):
- POST `/health/people/{person}/upload-batches` -> store (edit, throttle 10,1) 201 {batchId} | 200 {batchId, existing: true} | 409 {reason: consent_off|unavailable|notice_required, providers?, textNotice?}
- GET `/health/people/{person}/upload-batches/{batch}` -> show, Inertia page `Health/UploadBatch` (edit, throttle 60,1)
- GET `.../{batch}/status` -> status JSON (edit, throttle 60,1)
- PUT `.../{batch}/current` {itemId} -> 204
- PUT `.../{batch}/items/{item}/choices` {choices} -> 200 {choices}
- PUT `.../{batch}/items/{item}/adjustments` {brightness 50..150, contrast 50..200, bw} -> 200 {adjustments}
- POST `.../{batch}/items/{item}/rescan` {acknowledged?, providers?, textNotice?} -> 202 | 409 {reason: limit|done|consent_off|notice_required, providers?}
- POST `.../{batch}/items/{item}/continue` -> 200 {result, nextItemId, approved, rejected} | 409 {reason: not_ready} | 422 errors keyed entries.<key>.<field>
- DELETE `.../{batch}/items/{item}` -> 204
- DELETE `.../{batch}` -> 204 {removed}
- POST `/health/people/{person}/documents` (existing) with optional `upload_batch_id` -> 201 {document, item {id, duplicateOf}} | 422 with health.batch.err_full / err_duplicate / err_closed

Decision (recorded): the documents.store throttle rises from 30 to 60 per minute so a 50-file batch of small photos is not cut off; the batch uploader in 15-06 also waits and retries on 429.

Purpose: BULK-01 upload and resume entry, and the HTTP surface of BULK-04 to BULK-08.
Output: one route file, controller, request, DocumentController/StoreDocumentRequest/PersonPage changes, two Pest files.
</objective>
