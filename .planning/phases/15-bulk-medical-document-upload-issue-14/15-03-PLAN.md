<objective>
The system side of upload batches, built on the Phase 9 machinery (D-07): a tick that advances each open batch by at most one document, quota parking and self-resume through the existing waiting/resume path (D-05), the consent-withdrawal hook (D-06, consistent with Phase 13), and the 30-day expiry with explicit file deletion (D-02).

Decisions (Claude's discretion, recorded):
- The AI reads ahead of the member's review, one document at a time per batch; the review cursor is separate (15-04). Batch runs use the interactive queue `ai.queue`, count toward `ai.limits.max_active_global` and, like bulk rows, not toward the per-member active limit; they skip the per-document cool-down because a re-scan is an explicit member request capped at 5 per document.
- The run starts in the name of `items.requested_by` (set by a re-scan) or else `batches.acted_by` (the member who last acted on the batch). The job's existing access, consent and notice re-checks then apply unchanged; a member who lost access makes the run end cancelled(access), visible on the item, and any editor's re-scan takes over.
- Consent withdrawal keeps the batch, its uploaded documents and its saved choices; only AI work stops. Expiry still applies.
- Expiry: delete when `expires_at <= now()`, hourly. Files are deleted explicitly through MedicalDocumentStore after commit, because medical:prune-orphans has a 20-file circuit breaker.

Output: system query, kicker, two commands, schedule entries, consent hook, audit enum case, tests.

## Interfaces this plan provides (consumed by 15-04 and 15-05)

- `UploadBatchJobQuery::advance(string $batchId, CarbonImmutable $now): ?string` returns the extraction id to dispatch after commit, or null.
- `UploadBatchJobQuery::cancelBatchRuns(string $batchId, ?int $actorId, ?string $documentId = null): int` stops queued/waiting runs at once and asks a running one to stop; with $documentId only that document's run.
- `UploadBatchJobQuery::purge(string $batchId, ?int $actorId, string $action): int` (action 'deleted' or 'expired') returns how many unfinished documents were removed.
- `UploadBatchJobQuery::resetForConsent(string $subjectId): void`.
- `BatchKicker::kick(string $batchId): void` (advance in its own transaction, then dispatch).
- `AiRunQuery::recordAcknowledgment(Viewer $viewer, array $enabledKeys): void` and `AiRunQuery::acknowledgmentNeeded(Viewer $viewer, bool $acknowledged, ?array $shownProviders, bool $textNotice): ?array` (null when fine, else the enabled provider list for a notice_required answer), extracted from start() without changing its behaviour.
- `AuditEvent::MedicalUploadBatchChanged = 'medical_upload_batch_changed'` with meta keys subject, batch, action, count.
