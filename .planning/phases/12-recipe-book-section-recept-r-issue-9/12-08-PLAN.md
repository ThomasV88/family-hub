- `quantityInput.js`: `parseQuantity(text)` accepts decimal comma or dot, `a/b`, `n a/b`, vulgar fractions, returns a number rounded to 2 decimals or null for empty, NaN-free error state for exponent notation, zero, negatives and values over 9999; `formatQuantityInput(value, locale)` shows the locale decimal separator. The request still normalises server-side.
- Save flow: create sends JSON `fetch('/recipes', POST)` with the XSRF header pattern of `resources/js/Security/securityFetch.js`; 422 errors are mapped onto fields (line errors by index); on 201 it uploads queued photos sequentially through `recipePhotosApi.js` to `/recipes/{id}/photos` (multipart `image`), then makes the chosen main photo main if it is not the first, then `router.visit('/recipes/{id}')` and shows the saved toast. Photo upload failures after the recipe exists do not lose the recipe: the toast says the recipe was saved and the failed photos can be added in Edit (key `recipes.photos.some_failed`). Edit uses `router.put('/recipes/{id}', data)` with line ids; photo actions on edit call the 12-04 JSON endpoints immediately and replace the list from the response.
- `RecipePhotosField`: 96 px thumbnails, "Add photos" tile (ImagePlus, multiple file input `accept="image/jpeg,image/png,image/webp"`), hint "Up to 10 photos, JPG, PNG or WebP, up to 5 MB each", main photo with accent 2 px border, Star badge and `UiTag` "Main", overflow `UiMenu` per photo (Make main, Move earlier, Move later, Remove with danger confirm "Remove this photo?" / "Remove photo" / "Keep photo"), uploading skeleton tile, inline error "We could not use that picture. Choose a JPG, PNG or WebP image and try again.", "You can add up to 10 photos." at the cap. In create mode it manages local File objects with object URLs (revoked on unmount).
- Edit specifics: hint for shared recipes "Other members may be cooking from this recipe. Their ticks are kept for lines you do not remove."; changing shared to private shows the non-danger confirm "Make this recipe private?" before saving. Leave with unsaved changes: `UiConfirmDialog` "Leave without saving?" (Inertia `router.on('before')` plus `beforeunload`).
- Validation: inline `UiField` errors with `aria-live="polite"`, focus the first invalid field, "Add at least one ingredient." / "Add at least one step.", top `UiAlert` danger on request failure.
- Toast action: extend `useToast` with an optional `action {label, onSelect}` rendered by `UiToastRegion` as a 44 px button; existing toast calls unchanged.
