## Contracts

Routes in `routes/web/recipes-photos.php` (`whereNumber` on ids; names `recipes.photos.*`; writes `access:module,recipes,edit` plus `throttle:30,1,recipes.photos.write`; show `access:module,recipes,view`):
- POST `/recipes/{recipe}/photos` `recipes.photos.store`, multipart field `image` -> 201 `{photo: {id, position, isMain, version}, photos: [...]}`.
- PUT `/recipes/{recipe}/photos/{photo}/main` `recipes.photos.main` -> 200 `{photos}`.
- PUT `/recipes/{recipe}/photos/{photo}/position` `recipes.photos.move`, body `{direction: earlier|later}` -> 200 `{photos}` (swap with the neighbour; at the edge a no-op 200).
- DELETE `/recipes/{recipe}/photos/{photo}` `recipes.photos.destroy` -> 200 `{photos}`.
- GET `/recipes/{recipe}/photos/{photo}/{size}` `recipes.photos.show`, size `full|thumb` -> image/jpeg, `Cache-Control: private, no-cache`, ETag from path and version, 304 on If-None-Match, `X-Content-Type-Options: nosniff`.
- `photos` list shape everywhere: `[{id, position, isMain, version}]` ordered by position. 12-05's payload builds the URL strings `/recipes/{id}/photos/{photo}/thumb?v={version}` itself (same wave, do not depend on each other's code).
- Errors: 422 JSON `{errors: {image: [key]}}` with the keys above; a recipe with `recipes.photos.max_count` photos refuses with `recipes.image.err_count`.
- Access: recipe loaded through `Recipe::visibleTo` (404 hidden), photo `where recipe_id` (404 otherwise); writes need RecipeAccess::mayEdit (403 for a visible non-author). Members without Recipes view get 403 from the module middleware (same as the wishlist and shopping image routes, see 11-04 deviation).

RecipeImageStore additions: `add(Recipe, UploadedFile|string $bytes): RecipePhoto` uses `ImageProcessor::process($bytes, config photos.max_bytes, full_px, thumb_px)`, writes `{dir}/{ulid}-full.jpg` and `-thumb.jpg`, inserts the row in a transaction with a row lock on the recipe (count cap checked under the lock), first photo is main; files written before the insert are removed if the transaction fails. `makeMain`, `move`, `remove` (row delete in the transaction, files after commit, promote the lowest position to main if the main was removed), `sweepOrphans(int $olderThanMinutes = 60)`: files under `wish-images/recipes/` whose path is not referenced by `recipe_photos.path` or `thumb_path` and are older than the threshold.

Ops: add `'wish-images/recipes/'` to `WishImageStore::FOREIGN_PREFIXES`; call `RecipeImageStore::sweepOrphans` from `PruneWishlist` exactly as 11-04 wired the shopping sweep; add `recipes.photos.show` to the NoStoreDynamicResponses allowlist; nginx `location ~ ^/recipes/[0-9]+/photos$ { client_max_body_size 8m; include .../security-headers.conf; include .../fastcgi-app.conf; }` copied from the shopping block (do not add another `3m` block: ImportPreviewTest counts it); add a recipe line to `scripts/check-upload-limit.sh`.
