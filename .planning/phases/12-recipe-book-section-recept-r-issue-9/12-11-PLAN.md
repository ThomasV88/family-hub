| Boundary | Description |
|----------|-------------|
| web page text -> prompt | hostile, untrusted content reaching an agentic CLI |
| CLI output -> app | model reply treated as untrusted data |
| ai_calls -> admin page | content-free log shown to administrators |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-41 | Tampering | prompt injection from page text | mitigate | untrusted-data rules, per-run nonce markers with neutralised prefix, no tools (Codex shell off, web search disabled, read-only sandbox; Copilot all tools denied), schema plus server validator, draft only |
| T-12-42 | Tampering (XSS) | model output | mitigate | strip_tags, control and bidi removal, length caps, UI renders text only |
| T-12-43 | Information disclosure | page text or URL in logs or ai_calls | mitigate | log ban in Recipes/Ai and Recipes/Import (arch test), ai_calls has no content columns, exceptions content-free |
| T-12-44 | Denial of service | oversize prompt on Copilot argv | mitigate | max_prompt_bytes enforced in RecipeTask |
| T-12-45 | Integrity | medical path regression | mitigate | MedicalTask default, all medical tests unchanged |
| T-12-46 | Repudiation | kind rewritten after the fact | mitigate | guard function makes kind immutable; test |
