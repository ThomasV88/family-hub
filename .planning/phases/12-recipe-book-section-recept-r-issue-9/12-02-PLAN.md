## Where the UI contract overrides the research (12-UI-SPEC wins on stated behaviour)

- Units: the Shopping unit list (`shopping_units`, built-in plus administrator units), not a separate recipe unit enum. `recipe_ingredients.unit_id` is a nullable FK to `shopping_units` with `nullOnDelete` (an administrator deleting a custom unit leaves the quantity without unit, same rule as Shopping items).
- Categories: free text, starter set plus names already used in the family, max 3 per recipe (orchestrator: "max per research"), each max 30 characters (UI-SPEC). No fixed CHECK list.
- Limits: description 1000, step 1000, ingredient note 80, minutes 0..1440, quantity 0.01..9999 with two decimals, servings 1..99 nullable (D3; the form defaults to 4).
- No per-ingredient "do not scale" flag (not in the UI contract); rows without a quantity never scale.

## Schema contract (bigint ids, timestampTz, enum-like columns as string plus CHECK, explicit FKs; new tables inherit app-role privileges through default privileges)

- `recipes`: id; author_id FK users restrictOnDelete (same as tasks.creator_id; the app never hard-deletes users); title varchar(120) not null; title_key varchar(255) not null default '' (NameKey of the title, for "title matches first" ordering); description varchar(1000) null; visibility varchar(7) not null default 'private' CHECK in ('private','shared'); servings smallint null CHECK 1..99; prep_minutes and cook_minutes smallint null CHECK 0..1440; source_url varchar(2048) null; source_host varchar(255) null; created_via varchar(6) not null default 'manual' CHECK in ('manual','url'); search_key text not null default ''; timestamps. Indexes (visibility, created_at desc), (author_id, created_at desc).
- `recipe_categories`: recipe_id FK cascade; name varchar(30) not null; name_key varchar(90) not null; position smallint; PK (recipe_id, name_key); index (name_key).
- `recipe_photos`: id; recipe_id FK cascade; path varchar(255); thumb_path varchar(255); position smallint; is_main boolean default false; version int default 1; created_at. Partial unique (recipe_id) WHERE is_main; index (recipe_id, position).
- `recipe_ingredients`: id; recipe_id FK cascade; position smallint; name varchar(120) not null; name_key varchar(360) not null; quantity numeric(6,2) null CHECK (quantity > 0 AND quantity <= 9999); unit_id FK shopping_units nullOnDelete null; note varchar(80) null; index (recipe_id, position); index (name_key) is not needed (ILIKE scan at family scale).
- `recipe_steps`: id; recipe_id FK cascade; position smallint; body varchar(1000) not null; index (recipe_id, position).
- `recipe_member_states`: recipe_id FK cascade; user_id FK users cascade; favourite boolean not null default false; note text null; servings smallint null CHECK 1..99; updated_at; PK (recipe_id, user_id); partial index (user_id) WHERE favourite.
- `recipe_ingredient_ticks`: ingredient_id FK recipe_ingredients cascade; user_id FK users cascade; created_at; PK (ingredient_id, user_id); index (user_id).
- `recipe_step_done`: step_id FK recipe_steps cascade; user_id FK users cascade; created_at; PK (step_id, user_id); index (user_id).
