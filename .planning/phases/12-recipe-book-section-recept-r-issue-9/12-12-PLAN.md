## Contracts

- `SafeFetcher::__construct` gains an optional trailing `?string $userAgent = null` (default keeps `FamilyHubImageFetcher/1.0`). Nothing else in SafeFetcher changes; all wishlist fetcher tests stay green. 12-13 binds the recipe fetcher with `config('recipes.import.user_agent')`.
- `RecipePageReducer::reduce(FetchResult $r): ReducedPage` (pure, no network, no Laravel facades except config):
  1. Reject (`PageRejected` with reason `not_html`) when contentType is present and not `text/html`, `application/xhtml+xml` or `text/plain`.
  2. Gzip guard: body starting with `\x1f\x8b` is decoded with `zlib_decode($body, config decoded_max_bytes)`; failure -> `not_html`; result larger than the cap -> `too_large`.
  3. Charset: Content-Type header charset first, then `<meta charset>` or `http-equiv` in the first 4096 bytes; allow-list (utf-8, windows-1250, iso-8859-2, windows-1252, iso-8859-1, us-ascii); convert with `mb_convert_encoding`, fall back to `iconv //IGNORE`; verify `mb_check_encoding($s, 'UTF-8')`, else `not_html`.
  4. Parse with `DOMDocument::loadHTML` under `libxml_use_internal_errors(true)` and `LIBXML_NONET | LIBXML_NOERROR | LIBXML_NOWARNING` (never LIBXML_NOENT or DTDLOAD); restore libxml state afterwards.
  5. JSON-LD first: every `script` whose type equals `application/ld+json` case-insensitively; `json_decode` depth 32; bounded breadth-first walk (max 5000 nodes) through arrays, `@graph` and nested objects for a node whose `@type` (string or list, case-insensitive) contains `Recipe`; prefer the first with `recipeIngredient` (or legacy `ingredients`) and `recipeInstructions`. Compose labelled lines: `Title:`, `Description:` (first 500 chars), `Yield:` (text, number or list joined), `Prep time:`, `Cook time:`, `Total time:` (ISO 8601 parsed with `CarbonInterval::make` in try/catch to minutes, garbage ignored), `Category:`, `Ingredients:` one per line, `Steps:` one per line from a string, list of strings, `HowToStep.text`, or `HowToSection` name plus its `itemListElement` steps. Each string truncated to 1000 characters. kind `json_ld`.
  6. Microdata bonus: elements with `itemprop` recipeIngredient/ingredients and recipeInstructions inside `[itemtype*="Recipe"]` produce the same labelled lines (kind `json_ld` is not used; use `microdata`).
  7. Readable-text fallback: remove `script, style, noscript, template, svg, iframe, form, nav, header, footer, aside, button, select`, comments, and any element with the `hidden` attribute, `aria-hidden="true"`, or inline style containing `display:none`, `visibility:hidden` or `font-size:0` (whitespace-insensitive); choose the first of `[itemtype*="Recipe"]`, `article`, `main`, `[class*="recipe"]`, else `body`; walk text nodes inserting newlines at block boundaries; prepend `<title>`, `og:title` and meta description. kind `text`. A result with fewer than 40 letters -> `PageRejected('empty')` (JS-only pages).
  8. Sanitise every path: NFC normalise (`Normalizer`), drop control characters except newline, drop U+200B-200F, U+202A-202E, U+2060, U+2066-2069, U+FEFF, collapse runs of spaces and blank lines, replace `<<<` with `< < <`, cut at `config('recipes.import.max_text_chars')` on a line boundary, `cut` boolean true when anything was dropped.
- `ReducedPage` readonly: `kind` (json_ld | microdata | text), `text`, `cut`. `PageRejected` carries only a reason code from {not_html, too_large, empty}; never page content in its message.
