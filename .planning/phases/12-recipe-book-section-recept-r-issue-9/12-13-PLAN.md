## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| member -> start | arbitrary URL |
| worker container -> internet | outbound fetch to a member-chosen host |
| worker -> ai-worker | reduced page text handed to an agentic CLI |
| ai-worker -> database | model output stored as a draft |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-51 | Information disclosure / Elevation (SSRF) | FetchRecipePage | mitigate | SafeFetcher only (A-record check, IP pin, per-hop re-validation, ports 80/443, no userinfo, IPv4 only), runs in the worker container, never in php-fpm or the ai-worker; body never returned to the member; tests for private IP and redirect to metadata IP |
| T-12-52 | Tampering | prompt injection | mitigate | reducer stripping (12-12), RecipeTask nonce block and validator (12-11), no tools, draft needs review |
| T-12-53 | Denial of service / cost | import flooding | mitigate | 2 active, 20 per day, 10 global under an advisory lock; same-URL reuse; fail fast on quota; Copilot daily ceiling through AgentHealth |
| T-12-54 | Information disclosure | page text in failed_jobs or logs | mitigate | job payloads carry the id only; no log calls (arch test); source_text cleared at every terminal state |
| T-12-55 | Spoofing | another member reads or cancels an import | mitigate | every service method scopes by user_id (404 otherwise) |
| T-12-56 | Repudiation | medical notice reused for recipes | mitigate | separate recipe_providers column and protocol; test |
</threat_model>
